# Methods by package kind and scenario

Select the method for the package kind and scenario before choosing an instrument or a repair. Hold each reading to its run and each bar to its package, and carry neither to another package. A method's **Law** line names the rule that owns it, and "the law" in that block means that rule.

## Performance

### Reuse work at its valid lifetime

When construction or lookup repeats inside the work it supports, measure the repeated term, retain its result for the operation or entity whose identity makes it valid, keep first-use costs visible, and read cold and warm as separate claims.

- **Refuse.** A cross-call cache keyed by message count or a persisted call-scoped memo, because removal and appends preserve the count and read-once semantics are limited across concurrent writes.
- **Reading.** In the `@orkestrel/contract` package at commit `0f05405`, depth-6 construction reads “1.317 to 0.111 ms”, with object checks 2–4 percent slower. This saving is not additive with any other reuse reading.
- **Example.** `@orkestrel/contract` `0f05405`: sealed shapes, so a walk of a built shape runs one time.
- **Law.** `.claude/rules/quality.md` § Performance.

### Revert a speed-only change that misses its own acceptance

When a faster large fixture accompanies slower small consumers, set the improvement and no-regression conditions before the run, revert the helper and its call-site swaps when the no-regression condition fails or one faster cell is the only gain, record a missed improvement target as a miss, and retain the pins and bench.

- **Refuse.** Keeping a failed helper or its call-site swaps because one cell improves, because one faster large array does not override the small-consumer no-regression condition. Landing a speedup that weakens a published promise before a throwaway copy measures it, because the number must be weighed against the promise: deferring `schema` saves 4.7 of 36.6 ms on `@orkestrel/reason`, and `@orkestrel/contract` `d359d94` declines it.
- **Reading.** In the `@orkestrel/contract` package, on the bench retained at commit `09d0673`: “Small-fixture pool: 1.2061 [1.1400, 1.2760], or 20.6% slower.” The `arrayOf` ratio is 0.6843, but the `recordOf` ratio at 0.8416 misses its 20% gain target and small fixtures miss the 5% regression bound. A/A passes, so a passing instrument does not make the candidate acceptable. The percentages are this experiment's bars.
- **Example.** `@orkestrel/contract` `09d0673`: the fixed-array guard helper is reverted with no release, and the pins and bench stay.
- **Law.** `.claude/rules/quality.md` § Performance.

### Replace copy-on-append with an appropriate queue structure

When stream buffering recopies accumulated data for each delta, replace the copies with a queue that drains, move the head before each yield so the queue retains at most one taken value and no successor chain, prove output identity, and price generation and shape cases separately.

- **Refuse.** Inferring a gain from append microtiming alone, because generation and shape cases carry their own prices.
- **Reading.** In the `@orkestrel/agent` package at commit `dd8dee79`: “1078.2 ms before, 13.2 ms after”; A slope 3.03 to 0.98 and C slope 2.58 to 1.06. Case B ratio 1.0329 stays under this run's 1.05 bar, but still pays a measured 1.9–4.7% cost. Six processes per build, A/A passes, other load at most 4.6% per process. Sensitivity spins first under-deliver, and calibration is repaired before the final comparison.
- **Example.** `@orkestrel/agent` `dd8dee79`: the `Channel` class buffers in linked cells, a structure specific to this package.

### Own and freeze once, and price restoration separately

When repeated copies protect reads but dominate selection, copy the owned JSON, walk it with a worklist, freeze the copy so the input stays untouched, gate both repeated reads and hydrate, and state the changed mutation and aliasing behavior in upgrade guidance.

- **Refuse.** Freezing inside a reviver, because restoration is priced beside the repeated-read saving and the reviver's hydrate fails its gate.
- **Reading.** In the `@orkestrel/agent` package at commit `9745e36e`, selection reads “2136.7 → 780.5 ms”; the reviver's hydrate “52.6 → 73.7 ms” fails. Final copy/walk hydrate is 55.02 ms against 52.73/52.30 ms, ratio 1.0433. The kept slot reports equal digests and other load at most 1.7%. The 51106-judgment readings are report-only.
- **Example.** `@orkestrel/agent` `9745e36e`: the `JudgmentManager` class keeps the copy and worklist after the reviver candidate is reverted, and a host editing a snapshot judgment to migrate or redact it observes the ownership change.
- **Law.** `.claude/rules/quality.md` § Performance.

### Yield real host turns and prove the interleavings they add

When long synchronous work blocks an interactive caller, or cheap-looking yields consume a deadline, measure host turns, deadline cost, and unscheduled throughput separately, race cancellation where a supplied scheduler can remain pending, and test source removal, stale plans, and callback cancellation.

- **Refuse.** A microtask yield as a host turn, because resolving a promise is not proof that the host serviced its next turn. Scheduling reported as a speed-only edit, because scheduling adds interleavings. A raced host yield claimed as preemption, because it does not preempt arbitrary work.
- **Reading.** In the `@orkestrel/agent` package at pacing commit `77df10c2`, the maximum heartbeat gap reads “43.83 → 23.57 ms”, and correction and control both miss this run's 12.5 ms target. The reduction is retained without moving the target. A microtask control tests whether the heartbeat instrument sees a host turn. No cross-host yield equivalence follows.
- **Example.** `@orkestrel/agent` `77df10c2`: the `Classifier` and `Ledger` classes pace long work, and commit `069540aa` repairs cancellation for that pacing.

### Make persisted identity match the declared value semantics

When JSON persistence sorts keys and silently destroys memo hits, compare JSON values structurally, set categorical tie order explicitly, use an independent canonical-copy oracle with semantic negative controls, cover own `__proto__` and `constructor` keys with controls, and keep positional-prompt limits separate.

- **Refuse.** Storing consumer checkpoint state as opaque JSON text or changing the `@orkestrel/study` canonicalization, because real hosts still lose judgments and canonical bytes back the digests of that package. Claiming arbitrary JavaScript equality, because the comparator's domain is JSON rendering, not cyclic objects, bigint, or arbitrary `toJSON` behavior.
- **Reading.** In the `@orkestrel/agent` package at commit `a82c5985`, correction-1600 ratios are 0.915 and 0.918, and the change is retained for a predeclared correctness merit, not a speed target. Sorted-seed controls exercise the repaired path, and two quiet runs are recorded. No hydrate timing runs, because hydrate is untouched.
- **Example.** `@orkestrel/agent` `a82c5985`: the `matchesJSON` and `matchesJudgment` functions compare by value, overturning commits `c6e34379` and `f28d222e`, and the `@orkestrel/study` canonical encoding that exposes the defect stays.
- **Law.** `.claude/rules/patterns.md` § Admission and refusal.

### Index against realistic text and retain small-registry costs

When each message scans an entity registry, measure an index across registry sizes and real text, prove ordered matching equivalence, and publish Unicode and host limits.

- **Refuse.** A load detector or selector added to conceal a small-fixture cost, because selection needs a free exact count, parity, and a measured sweep.
- **Reading.** In the `@orkestrel/agent` package at commit `c70e64cd`, control-1600 selection reads “131.98→59.67 ms”; real-text lookup at registry sizes A=1 and A=3 costs “+12.08 and +9.20 ms per 1600 texts”, while A=12 saves 6.88 ms. Those costs are accepted alongside scale gains. Independent Unicode controls are required, with “a browser's tables unread” as the stated limit.
- **Example.** `@orkestrel/agent` `c70e64cd`: an index replaces the per-message registry scan around the `normalizeWord` and `matchEntities` functions, whose placement at that commit is unchecked.
- **Law.** `.claude/rules/quality.md` § Performance.

### Search a cut instead of rendering every candidate

When large text exposes repeated per-line rendering or splitting that short-message fixtures hide, count the term, search the cut, prove semantic boundaries with a pin whose accepted amendment has a cut that crosses a flip, and state the monotonicity assumption.

- **Refuse.** Inferring arbitrary-cut correctness from ordinary seed digests, because equal digests close only the measured shapes and the fitting predicate must stay monotonic in the searched region.
- **Reading.** In the `@orkestrel/agent` package at commit `275c0dab`, correction paste200 reads “3924.77→106.90 ms” and control reads “3813.59→64.82 ms”. The 200 KB correction exponent falls 2.546 to 1.185, but 53.2 ms added cost stays recorded rather than chased. The comparison departs to separate slots, with a roughly 2% resolution limit.
- **Example.** `@orkestrel/agent` `275c0dab`: the `#trim` method of the `Ledger` class searches the cut instead of rendering each candidate.

### Close a cost question without building an optimization

When a suspected whole-set store cost has no demonstrated consumer impact, measure the actual driver and growth first, and leave the mechanism unchanged if the reading closes the question.

- **Refuse.** Extending one driver's evidence to every driver, because other drivers stay unmeasured.
- **Reading.** In the `@orkestrel/agent` package, on the memory driver: “set at 2000 revisions: 4.563 ms”; slopes set 1.025 and get 1.003. No before/after candidate is compared. The question closes for the memory driver only, using the stated quiet slot and some adjacent host readings.
- **Example.** `@orkestrel/agent` `no commit recorded`: the `MemoryMemoStore` class stays unchanged, because no optimization is required.
- **Law.** `.claude/rules/quality.md` § Performance.

### Remove exponential work before adding a bound around it

When shared cyclic graphs repeatedly traverse the same structure, change precedence so one linear walk decides.

- **Refuse.** Bounding the old mechanism as the repair, because a guard limit alone does not justify retaining an avoidable exponential mechanism.
- **Reading.** In the `@orkestrel/contract` package at commit `aadb739`, on a shared cyclic graph: “22 levels 4.56 s to 163 µs; 41 levels 253 µs.” This reading closes the recorded cost repair, not later re-audit findings or package readiness. Host conditions and uncertainty are absent, and the bounded approach has no after-build.
- **Example.** `@orkestrel/contract` `aadb739`: the `#measure` method checks the already captured cycle before height calculation instead of taking the `#trace` path, and other files in that commit carry no attributed gain.
- **Law.** `.claude/rules/quality.md` § Performance.

### Dispatch a union through its declared discriminant

When parsing tries arms in sequence even though a literal property identifies an arm, use that property to select the arm and retain the union's contract.

- **Refuse.** Generalizing this dispatch to nondiscriminated unions, because no literal property identifies an arm there.
- **Reading.** In the `@orkestrel/contract` package at commit `4dff475`: “Last arm 20.7 to 4.1 µs.” Other arm costs, uncertainty, and host conditions are not supplied.
- **Example.** `@orkestrel/contract` `4dff475`: a union parse selects its arm by the literal property, and this multi-purpose commit makes no claim that every changed file implements union dispatch.
- **Law.** `.claude/rules/quality.md` § Performance.

### Enforce a bound before paying the refused work

When a validation limit is read only after ownership allocates or a parser traverses expensive input, measure each public door separately and count the loop before rewriting it.

- **Refuse.** A bound sized only from the `is` fixture, because every door pays a different prefix of work before refusal. An accepted bound claimed as repaired complexity, because the two are separate claims.
- **Reading.** In the `@orkestrel/contract` package, on the `is` fixture: “createContract spent 1.2 GB before refusal”, and the `cloneShape` function costs about eight times the `is` fixture. This reading precedes the door-bound carrier, measures no after-repair cost, and stays a separate checkpoint from readings at other doors and packages.
- **Example.** `@orkestrel/contract` `32b987b`: the door-bound carrier, with boundary proofs.
- **Law.** `.claude/rules/patterns.md` § Admission and refusal.

### Price the complete route before optimizing its kernel

When a computational kernel looks faster on a worker or in another representation, separate compute, validation, and copy or freeze cost from the rest of the route, distinguish transient peak from retained memory, and compare the actual public result rather than a rounded summary.

- **Refuse.** A worker-routing recommendation without a crossover, because a router needs a measured decision boundary after all route costs. Tiny-model cost scaled per parameter, because that scaling overstates larger-model work. Removing a safety check on these readings, because no reading here authorizes that removal.
- **Reading.** In the `@orkestrel/learn` package, on the research comparison at 8 subjects and 24 factors: “Guard 1.99 ms of 2.17 ms at 8 subjects and 24 factors”; worker/inline flattens near 1.7, and all six app holdouts prefer inline. This reading is diagnostic evidence, not a landed speed repair, and host identities differ between archived and fresh runs and stay separate.
- **Example.** `@orkestrel/learn` `no commit recorded`: a diagnostic comparison that closes with no worker-routing recommendation.
- **Law.** `.claude/rules/quality.md` § Performance.

## Measurement

### Calibrate the comparison, not merely the timer

When a timing claim sits near noise, timer resolution, or another host's absolute bar, define the marked region, warm it, add a calibrated delivered slowdown beside the interleaved comparison, report process-level uncertainty, preserve semantic digests, and record a missed target apart from a failed keep boundary.

- **Refuse.** Profiler shares, whole callback time, or a nominal spin as the gate wall, because timer quantization and work outside the mark move the reading and CPU resolution could exceed the short measured region. Forced collection for timing or an under-delivered spin as a control, because a control's delivered effect and its interference must be measured. A fixed sample count, because no universal sample count follows. A campaign's earlier build quoted as the published baseline, because the `@orkestrel/reason` hardened-build import at 93.3 ms is not the published artifact, recorded as 19.44 ms at commit `f8646a5`.
- **Reading.** In the `@orkestrel/contract` package at commit `32b987b`, on the `@orkestrel/reason` build: a loaded-host reading of 37.57 ms against 35 ms, while interleaved readings of 35.78/36.68 ms attribute 0.9 ms (2.5%) to the change. Counts and bars are run-specific. The `c_diff` expression is a derivation, not a cited formula, and external timing and statistical references stay untraced.
- **Example.** `@orkestrel/contract` `32b987b`: the repair carrier of the door bound, whose interleaved comparison separates the change from host load, and the scratch comparison drivers sit outside that commit.
- **Law.** `.claude/rules/quality.md` § Performance.

### Derive the performance stop from the consumer

When an optimization lacks an economic stopping point, price hydrate through first selection against measured model time, include message bytes and real text beside the count, and reopen deferred work on its explicit consumer-cost trigger.

- **Refuse.** A budget taken from an unmeasured model call, because the stop derives from measured model time. A count-only load, because message bytes carry a cost that the count hides. A retroactive slope bar on held share-only work, because a bar belongs to the run that set it.
- **Reading.** In the `@orkestrel/agent` package, on the measured 4B call: “660 ms derives from 5% of 13206 ms, rounded from 660.3 ms.” The real 290-message selection reads 62.47 ms. The cross-call projection closes unbuilt, reopening above 10% of consumer model time to first token. The 660 ms budget comes from the measured 4B call, not an unmeasured 2B call, and the 5% and 10% figures belong to this run.
- **Example.** `@orkestrel/agent` `no commit recorded`: the stop decision around the `Ledger` class request and select path holds share-only work and changes no implementation.
- **Law.** `.claude/rules/quality.md` § Performance.

### Separate model perturbation from cache-identity changes

When repeat or sham arms are supposed to measure noise, check whether the perturbed parameter also keys persisted judgments, account for warming on a nongate goal, preserve raw spend, compare only within a sealed lineage, open another lineage when the instrument changes, record an unreached stratum as unreached, and disclose an after-data exception with its beneficiary and owner ruling.

- **Refuse.** A changed seed read as pure noise, because sampling parameters can also be cache identity. A heuristic subtraction of re-asks, because the `Earlier message:` subtraction misses pair cases. A quality gate as proof that a cap loses nothing, because a quality gate that cannot see missing filings cannot certify that cap. A floored instrument read as a loss or a keep, because a floored instrument shows no gain and measures no loss. A substitute arm for an unreached stratum, because a reachable stratum on another arm answers a different question. An after-data exception read as a standing rule, because that exception rewrites no future gate.
- **Reading.** In the `@orkestrel/agent` package, on the repeat arm of the memory study: “Repeat re-asked 184 held judgments, 243.1 s.” This reading stays a separate checkpoint from the burst readings and compares with none of them as one experiment. No single commit closes the perturbation and lineage observations, and external nondeterminism and cache sources stay untraced.
- **Example.** `@orkestrel/agent` `1a29fcf1`: the `LedgerCorrectionOptions.narrow` option stays at default false, and its topic-only and free-text missed-case limit stays specific to this package.

### Size runs from observed work and preserve failed-run accounting

When model runs or labelers threaten to consume a cap before producing inspectable evidence, project from measured wall, model seconds, growth, and launch overhead, use short sealed segments, retain each arm, revise by lineage, charge unsealed work manually, state absent terminal accounting and an unread grade after a valid seal, and diagnose profile admission separately from package defects.

- **Refuse.** Raising only a byte bound, because that raise renames the failure and leaves completion unaddressed, so give each repair its own failing receipt. A calibration observation as a profile policy, because a calibration observation is not a conservative admission setting. A shaped proxy reply as replay, because a shaped proxy reply is not exact replay.
- **Reading.** In the `@orkestrel/agent` package, on the memory study: goals 1–24 consume 711.7 s, the checkpoint holds 318725 bytes with 9.4–9.9 KB growth per goal, and launch adds 17–19 s. These readings are internal measurements with no external bibliography traced, and no single corrective commit belongs to them.
- **Example.** `@orkestrel/agent` `no commit recorded`: “A profile value stopped the compaction arm, not a defect in Agent or Study”, and no successful fold comparison follows from that stopped arm.
- **Law.** `.agents/orchestration.md` § Hold the plan.

### Rehearse a long run at full scale

When a run will hold the host or a model for hours, rehearse it on the real frozen shape with real inputs and no model, let `verifier` run it and `checker` read its files, and read the rehearsal's own cost before the window opens.

## Settled arguments

- When a proposal caches every cheaper repeated operation, answer that a cache earns its lifetime and complexity only on its own measured term. Reopen only on that operation's own shown saving.
- When a proposal treats a missed target as a failed keep rule, answer that improvement targets, no-regression conditions, correctness merits, and owner exceptions are distinct dispositions.
- When a proposal quotes a figure from earlier in a campaign as the published baseline, answer that a campaign's earlier build is not the published artifact.
- When a proposal treats serialized order as judgment identity, answer that identity must survive the persistence transformation the public contract recommends.
- When a proposal calls a seed change pure noise, answer: inspect all identities the perturbation changes before interpreting variance.
- When a proposal offers a quality pass as proof that an optimization loses nothing, answer: measure the behavior the optimization can remove, not a convenient quality proxy.
- When a proposal gives an unreached gate another seed, answer that a reachable stratum on another arm answers a different question. Reopen only on a rewritten question.
- When a proposal reads scripted timing as proof of model usefulness or browser behavior, answer that a receipt covers the mechanism and host it drove.
- When a proposal adds another phrase-specific repair to a parser, answer that reader laws can generalize and vocabulary tuning needs whole-model evidence. Reopen only for a class of wrong decisions through the complete model.
- When a proposal calls a stricter check safer, answer that strictness names an owner, a representation, a stage, and a refusal direction.
- When a proposal makes an absent field approve, refer, or ask, answer that missing data is unread and only reached input faults become questions.
- When a proposal reduces approval wiring to an ID, answer: correlate the actual waiting call, not a visible name or loop event.
- When a proposal reads a failure as rollback or as no hang, answer: state the particular transaction and cancellation boundary rather than a universal.
