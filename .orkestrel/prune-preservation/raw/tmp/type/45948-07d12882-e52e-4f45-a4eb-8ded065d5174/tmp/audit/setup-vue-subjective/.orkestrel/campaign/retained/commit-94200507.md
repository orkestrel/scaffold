docs(skills): tighten the journey and Bootstrap skills against measured evidence

Every change here survived an adversarial verification pass that read the
files, refused what it could not substantiate, and rewrote what it could
substantiate but found mis-stated. Most proposals were refused.

The journey skill.

The statechart family fired on "a journey drives a control that carries
state", which is every control. It now fires on a transition of an entity
carrying its own state and event vocabulary, and `statechart.md` states what
that excludes: a view-local reactive ref is not such an entity, and a union
declared solely to type a table is barred by `AGENTS.md` § Design laws. A
positive redirect carries the obligation that ruling used to drop — assert the
state a control announces beside every drive that sets it, and on an unselected
sibling, whether or not the family applies.

Journey law 8 forbids a guarded interaction step. A step gated on whether its
control exists or is reachable passes whether or not the control was there, so
a run goes green on a surface that removed it.

`pressKeys` is not a verb `@orkestrel/test` publishes. The package's browser
barrel names `userEvent.keyboard` from `vitest/browser` as the door focus
arrives through; the skill carried that sentence with the verb mis-rendered, so
five sites named a symbol that does not exist. Each site is restored to the
published door: the closed input list, the verb table, two prose lists, and the
element-taking population row, which drops it rather than substituting, because
a targetless key sequence is not a journey verb.

`styles.md` records what the variant channel carries: Vitest `provide` takes
serializable values, so a per-variant project provides `name`, `width`, and
`height`, and `apply` runs inside the test.

The Bootstrap skill.

A refused browser capability had one instruction — "tolerate unavailable
storage" — which names no action. It now has a contract: paint before you
persist, catch at the boundary that makes the call, default a refused read to
the state a first-time reader gets, keep the action working for the session,
and say nothing about a refusal the person never experiences. The colour-mode
reference points at it instead of repeating it.

The wrapped-target rule is measured rather than reasoned. On a served page a
wrapped inline link paints disjoint per-line rectangles and its bounding-box
centre resolves to the ancestor; `line-height` widens that gap, padding narrows
it, and `display: block` collapses it to one rectangle. The rule bans the
remedy that aggravates the defect rather than the one that mitigates it.

`.agents/skills/**` is vendored into `dist/host`, so `host.json` moves with
these files and this release re-propagates to every target through `repair`.
