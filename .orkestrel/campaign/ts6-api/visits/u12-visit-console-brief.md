## Steps

1. `git status --short` (expected clean) and `node -e "console.log(require('@orkestrel/scaffold/package.json').version)"` (expected the head-start version the Orchestrator's log names).
2. Remove the `vite-plugin-dts` row from `package.json` `devDependencies`; touch no other row.
3. Rewrite each `configs/src/vite.<face>.config.ts` as the Context states.
4. `rm tests/distribution.test.ts`, then `npx scaffold repair --offline`, then `npx scaffold audit --offline`; report both outputs whole. `repair` may also refresh vendored files and guide mirrors; report every path it wrote.
5. `npm run format:check`, `npm run lint:check`, `npm run check`.
6. `npm run build`; then `ls dist/src/*/index.d.ts dist/src/*/index.d.cts` and `head -5` of each `index.d.ts` (the rollup writes the `.d.ts` per face and copies it to `.d.cts` for the `require` condition the exports map names, as scaffold's own `dist/src/` shows).
7. `PATH=/opt/npm11/bin:$PATH npm run test:distribution`.
8. `git status --short` and `git diff --stat`.

## Output

Write `tmp/units/ts6-u12-visit-report.md` with each step's command, exit code, and last lines; every criterion below with PASS or FAIL; the list of paths `repair` wrote; and any deviation. Return it as your final message.

## Deviation contract

Stop and report when a face's config does not carry the `dts(` shape the Context states, when `repair` or `audit` reports drift in a file this brief does not own, when a gate fails in a file outside the owned set, or when the build emits no `index.d.ts` for a face. Comment wording is yours.

## Acceptance criteria, cheapest first

1. `grep -n "vite-plugin-dts" package.json configs/src/*.ts` prints nothing; `grep -c "declarationRollup(" configs/src/vite.*.config.ts` reports one call per face.
2. `head -20 tests/distribution.test.ts` names no `typescript` specifier, and `npx scaffold audit --offline` reports no drift.
3. `format:check`, `lint:check`, and `check` exit 0.
4. `build` exits 0 and emits `dist/src/<face>/index.d.ts` and `dist/src/<face>/index.d.cts` for every face, so the unchanged exports map resolves both conditions.
5. `test:distribution` under npm 11 exits 0.
