## Steps

3. Rewrite each `configs/src/vite.<face>.config.ts` as the Context states.
4. `node node_modules/@orkestrel/scaffold/dist/bin/main.js repair --offline`, then `node node_modules/@orkestrel/scaffold/dist/bin/main.js audit --offline`; report both outputs whole. `repair` writes `tests/distribution.test.ts` back and may refresh vendored files and guide mirrors; report every path it wrote.
