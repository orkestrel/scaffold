# Brief — ts6-dts-absorb (absorption, read-only)

## Role and engine

`grok`, Cursor Grok, through the wave's launcher. Read-only: never create, edit, or delete a file, and never run a command that changes a tree. The shell tool is refused inside this bench; read files directly and reconstruct nothing from memory. Perform the assignment directly and spawn nothing.

## Objective

Distill, with `file:line` pointers, how the installed `vite-plugin-dts` and `unplugin-dts` emit TypeScript declarations and roll them into one file per entry, so the Orchestrator can decide whether a `tsc --declaration` emit plus a direct `@microsoft/api-extractor` call reproduces the same single-file rollup without the in-process `typescript` API. The owner's constraint: the fleet stays on `typescript` 6.0.3, removes every use of the in-process compiler API (TypeScript 7 drops it), and keeps one declaration file per published face in `dist/`.

4. **Post-processing.** Every transform the plugin applies to the rollup text after api-extractor writes it: `staticImport`, `clearPureImport`, `insertTypesEntry`, `copyDtsFiles`, `beforeWriteFile`, `afterBuild`, banner and footer, `pathsToAliases` (how `paths` such as `@src/core` are rewritten), `strictOutput`, `cleanVueFileName`, the `.d.cts`/`.d.mts` handling, and the order they run in.
