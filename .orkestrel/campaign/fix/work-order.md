# Breaking-change work order (deferred from fix round 1)

Each row is a verified DRIFT or DRIFT-RESHAPE repair the fix round deferred because applying it
moves the published surface: a renamed or removed export, member, event, option key, or union
member, a non-additive signature change, or an unpinned behavior change. The finding text and
the corrected repair live in the package dossier under `fix/<package>.md`; the writer's reason
for deferring is quoted from `fix/reports/<package>.md`.

Rows are grouped by publish layer from the catalog. Applying a layer's rows obliges every runtime
dependent of that package to re-pin and republish in layer order, so a wave that takes this work
order runs L0 first and L6 last. Nothing here is applied; each row awaits the user's approval.
