## Deviations

Three deviations, none blocking; all gates ran green afterwards.

1. s06-17 — the lane-corrected repair has no legal placement. Both lanes ask for the shared definition-to-snapshot-to-`new Workflow` build step extracted into a helper that `factories.ts`, `WorkflowManager.ts`, and `WorkflowRunner.ts` all import. A function that constructs a live entity is an entity factory, and `.claude/rules/architecture.md` § Centralized-file pattern places it in `factories.ts` — which is the cycle's other end. The only files that may hold a module function are the centralized kinds `CENTRAL_SOURCE_FILES` names in `tests/setupPolicy.ts`, and `helpers.ts` and `validators.ts` are barred from importing an implementation class, so no other file can host it. I applied what removes the cycle and keeps the stated direction true: the shared steps already extracted (`captureWorkflowOptions`, `definitionToSnapshot`, `cloneWorkflowSnapshot`) are imported by all three, and each site makes the one remaining `new Workflow(...)` call itself, exactly as `WorkflowRunner` already did and its comment records. One lane forbids building inline in `WorkflowManager`; I could not honour that and the placement rules at once, and `AGENTS.md` outranks the dossier.

2. s06-05 — `#cancelled` was folded into `runSignal.aborted` at its nine call sites rather than moved to `helpers.ts`. Both lanes list it among the predicates to move, but `cancelled(signal) => signal.aborted` is a rename-only wrapper over a platform primitive, which `.claude/rules/architecture.md` § Wrapper test bans outright, and moving it to `helpers.ts` would publish it. Folding it in is the finding's own original repair line. The other five predicates moved as the lanes direct.

3. s06-04 — `RunHolder` declares one mutable member, which is in tension with the `AGENTS.md` rule that interface properties are readonly. The cell is the mutation: the run-level cancel listener closes over it so it always aborts the phase runner that is live when the cancel fires, and a fresh cell per `execute` is what keeps a nested run from clobbering the outer one. A readonly member cannot express that, and both lanes require the type to be named in `types.ts`. The TSDoc states the mutability and its reason.

Also worth flagging, not a deviation: several findings were applied only in part, and each such note says so explicitly. s06-12 landed its deduplication and guard wiring but defers the constant renames and deletions as breaking. Four new exported functions, one class, and seven types now reach the barrel; each carries a guide Surface row and, where it is a function, a TSDoc `@example`, so `tests/guides.test.ts` parity passes. `guides/workflow.md` carries pre-existing banned prose terms (for example `e.g.` in the `DeferredInterface` row) that s06-29's file list does not reach; I left them rather than widening scope.
