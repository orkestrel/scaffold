test: prove the page composition from the packed artifacts with no request of its own

The distribution project gains a second isolated consumer that installs the packed workspace beside
the registry `@orkestrel/agent`, `@orkestrel/tool`, and `@orkestrel/ndjson` artifacts, then drives a
real Chromium page against it under recorders armed after the page and its modules load: the
browser's own request log, and a counter around the page's global transport.

The page loads every artifact over an import map the proof derives from the consumer's own
installed `exports` and answers from its `node_modules`, so no bundler stands between the published
files and the page. A specifier the installed tree serves nothing for stops the stage rather than
falling back to a bundler, and the receipts assert what the walk reached: every file inside an
installed package, every mapped target among them, the set closed under the relative edges those
files name, and no nested install beneath the consumer's own `node_modules` to make that
resolution a fiction.

The receipts it reads:

- the page evaluates each root entry the installed agent's own module names, and every one of them
  publishes a defined export;
- an installed agent runs a page tool that writes into the document, with neither recorder
  reporting a request;
- `createPageServer` connects, lists, calls, and refuses a later call after `stop`, the listing
  carrying the tool's `title` and its `pure` annotation back off the wire;
- an agent whose registry holds the pair's tools dispatches into the hosted server, its own
  registry entry keeping that `title` and annotation, and a name the server does not hold comes
  back as a failed tool result;
- `abort` on the agent's run reaches the hosted handler's own execution-context signal;
- an agent over `createRelayProvider` against a `createRelay` fixture on `127.0.0.1` spends one
  relay request per model turn and runs its page tool in the page;
- that relay refuses a turn presenting a credential the fixture does not hold, so an authorization
  that stopped being enforced fails this proof;
- one deliberate request raises the request log and the counter, the control the empty readings
  rest on.

The relay's server half is a real consumer application driven as a child process, so the proof
composes published artifacts on both sides of the wire rather than importing this repository's test
toolkit into the page. The scratch tree is removed whether or not the stage opened, and the guide's
`## Tests` section names each receipt and states that the project runs from `prepublishOnly`.

Campaign records live in the scaffold checkout under `.orkestrel/campaign/`.
