## Execution

TTTDD. Behaviours to pin, each with a test named for what it proves:

- A guide fetch that fails (network refusal, `404`) for a name with no present target copy
  resolves from the hosted guide, writes the mirror, sets `provenance.guides` to `'floor'`, and
  the command exits `EXIT_DRIFT`.
- A live fetch still reads `'live'` and wins over the floor.
- A name with a present target copy and a failed fetch keeps the present copy (the snapshot is
  the write precondition) and reports the unresolved path.
- A registry outage (`upstream.catalog()` throwing) performs the guide-only partial operation:
  declared names by default, the hosted catalog for `--all`, the target's own package excluded,
  the catalog table and dependency ranges untouched, a `note` in the result, no empty catalog
  written, no live version evidence claimed.
- `audit` emits a `Question` for a present foreign mirror whose bytes differ from the hosted
  guide, worded "differs from the hosted guide", naming `catalog`, outside the repair findings so
  `repair` never overwrites a present mirror.
- No new verb, no new flag, no new `Mirror` member beyond what the unknown settles.
