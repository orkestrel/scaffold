## What the proof asserts

`tests/setup.ts` is host-independent by construction — no `node:*`, no DOM, no Vue — so the whole
of its contract is reachable in the Node `setup` project and no half is deferred to another suite.
The file states that in its header. Each expectation is hand-written or derived by a second
mechanism the module does not share: the language's own numeric constants, `Object.hasOwn` read
against `in`, `Object.keys` read against a dotted key, the reason engine's own returned object, and
the corpus builders read against the vocabulary tables.

- **`expectSymbolic`** — returns the engine's own result object, narrowed enough to read
  `solutions.total` without a cast; refuses a real batch from `Reason.reason([{}, {}], …)` with
  `Expected a single result, got a batch array`; refuses a real `LogicalResult` naming the reasoning
  it got. The accepting case runs `createSymbolicReasoner().reason` over a `total = x + 1`
  definition seeded with `x: 5` and asserts the hand-derived `6`.
- **`EXTREME_NUMBERS`** — frozen; carries finite values only, so a non-finite case is named at its
  own site; carries both signed zeros, which `indexOf` cannot tell apart and `Object.is` can; spans
  past `Number.MAX_SAFE_INTEGER` and below `Number.MIN_SAFE_INTEGER` through `Math.max` and
  `Math.min`, and holds a positive value under `Number.EPSILON`; carries the `0.1`/`0.2`/`0.3`
  membership beside the float sum that contradicts it.
- **`TRICKY_KEYS`** — frozen and duplicate-free; carries prototype names a bare `in` read answers
  for while `Object.hasOwn` refuses every one of them; carries the empty key and an astral key whose
  code-point length is one while its code-unit length is not; carries a key decomposition rewrites,
  so a lookup normalizing to NFD misses it; carries `a.b` as one key, proven through `Object.keys`.
- **`INTERPRET_ACTIONS`** — frozen; names an action for every intent the corpus templates declare.
  The expected set comes from the builders, not from a list restated here.
- **`INTERPRET_DOMAINS`** — frozen; keys a keyword list by every domain the corpus templates claim,
  each list naming its own domain; every keyword lower-case and non-empty, matching text a
  classifier has normalized.
- **The corpus builders** — return a fresh graph per call, so one suite cannot reach another;
  replace an overridden field wholesale and leave the rest at the corpus default; identify each
  template with its own definition under an id no sibling repeats; give insurance a `deductible`
  default no mapping can supply plus the `monthly` computation; require the insurance `age` and
  nothing in eligibility; give eligibility multi-word aliases for proximity scoring; give the loan
  template a domain no sibling claims; give statistics one alias-free `value` mapping.
- **`buildInterpretation`** — builds a completed turn whose entities, mappings, and subject agree,
  read through `resolveField` from `@orkestrel/contract` rather than a reimplemented path read;
  merges an override over the default turn and returns a fresh graph each call.
- **`seedInterpretContext`** — adds every given turn to a real `InterpretContext`, in order; returns
  a distinct empty context for no turns. A comment names the ring-buffer cap, the entity flattening,
  and teardown as the `InterpretContext` suite's subject, not this file's.
- **`isBrowserVuePath`** — accepts `app/browser/views/Home.vue` and its backslash form; refuses the
  `app/server/` sibling, the `app/browserless/` prefix lookalike, and a nested `src/app/browser/`
  repeat.
