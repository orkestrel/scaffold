## What each proof asserts

Both files import the module under proof and assert; neither setup module was touched. Every
expected value comes from a literal, from host reflection, or from a second mechanism that can
disagree with the module — never from the module's own derivation.

### `tests/setupServer.test.ts`

The module is Node-only, so the proof uses real Node resources: `node:vm` realms and the real V8
collector. One case per contract:

- **foreign realm sources / record and string declaration** — `createForeignRecord` and
  `createForeignStringShape` answer the declared structure while `instanceof Object` is false,
  their prototype is not this realm's, and that prototype's `constructor` is not this realm's
  `Object`.
- **foreign realm sources / pattern** — `createForeignRegExp` honours the requested source and
  flags (`/a+/gi`), defaults the flags (`/b/`), is not `instanceof RegExp` here, and still answers
  `[object RegExp]` to the brand every reader identifies a pattern by.
- **foreign realm sources / prototype** — `createForeignPrototype` answers a distinct object per
  call, never this realm's `Object.prototype`, with a null prototype above it and real function
  values behind the mandated names. A member installed on one call's prototype reaches neither the
  other call nor this realm.
- **weak reference collection** — an unreachable target derefs to `undefined` after the request; a
  target the caller still holds survives it, which is what proves the request is bounded rather
  than looping; and `runInNewContext('typeof gc')` answers `'undefined'` afterwards, so the
  exposure is undone.

### `tests/setup.test.ts`

`tests/setup.ts` exports roughly ninety-five names; the consuming suites (`tests/src/core/**` and
`tests/guides.test.ts`) drive them as a much smaller set of behavioural contracts, and the proof
takes one case per contract. Cases, by group:

- **error capture** — `captureContractError` returns the coded error (`code === 'bound'`) and
  raises its own named failure for an operation that returns and for one that throws a
  non-`ContractError`. The control expectation comes from vitest's `toThrow(ContractError)`, not
  from the `attempt` and `isContractError` pair the narrower dispatches through.
- **redirection instruments** — `replaceIntrinsic` installs and restores the exact descriptor after
  a throw and refuses an absent member; `pollutePrototype` installs an accessor for an absent key,
  removes it after a throw, and refuses an owned key; `replaceAccessor` replaces a getter and
  refuses a data member; `replaceStringIterator` and `replaceStringSlice` install a getter reached
  during the operation and restore after; `redirectIntrinsic` arms a replacement row and a
  pollution row through their own installations, reports `armed`, and carries
  `createInertOutcome`'s unarmed answer; `throwSentinel` throws one exact value when called and
  when constructed, with a non-constructible arrow as the outside control; `captured` answers
  honestly while `Object.getOwnPropertyDescriptor` is replaced by a liar; `denyRecognition` makes a
  genuine `ContractError` fail its own `instanceof`; `ReentrantPollution` arms from inside the walk
  that observes its source and restores on request; `createWorkBound` answers the lie to its limit
  and then throws the overflow, tallying every ask.
- **terminal corpora** — every row of `TERMINAL_CONSTRUCTORS`, `TERMINAL_HOOKS`, and
  `TERMINAL_MEMBERS` is frozen, uniquely labelled, labelled for the member it points at, and
  matches `Object.hasOwn(target, key)` against its `via` — the ownership fact is read off the real
  target, so a row whose installation no longer matches its member is named. Each table's
  membership rule is asserted separately (the four global collection constructors; symbol keys
  only; string keys and replacement only). `OWNED_MEMBERS` rows are writable prototype members
  whose label maps back to a callable export of the core barrel that owns that prototype.
  `lieIntrinsic` arms a substitute, reports `installed && control()`, restores the honest member,
  and refuses an absent one. `findVacuousControls` names a control that answers before arming;
  `findInstallationControls` names a control that reads member identity and one whose member is
  absent, while staying silent for a control that observes behaviour. `TERMINAL_LIES` rows are
  frozen, uniquely labelled, and each owns the member it lies about.
- **published value fidelity** — `fingerprintOwnership` reports frozenness, sorts own data keys,
  closes a cycle with `<edge>`, skips `length`, and never invokes an accessor (proven with a
  throwing getter). `publicDoors` builds fresh frozen rows per call with unique labels, the
  declared refusal population, and exactly one `raw` row, `matchesRecordBrand`.
- **record brand forgeries** — `RECORD_BRAND_MEMBERS` names own non-enumerable function values of
  this realm's `Object.prototype`; `forgeRecordBrand` reparents to `null` and stamps this realm's
  real values while `forgeBlankBrand` stamps `undefined`; each declaration fixture carries
  `type: 'string'` and `min: 1` with the prototype state it names (untouched, null-based,
  forged-plus-`escape`, forged-exactly, blank); the proxied route answers a realm's questions
  through traps while the class keeps its real chain and its live method.
- **pattern fixtures** — `PatternFixture` routes the named field to the carrier and counts every
  conversion, and its accessor form answers a fresh frozen pattern per read; `SingleReadPattern`
  answers one `source` observation per produced pattern, refuses the second, and tallies across
  patterns.
- **retention fixtures** — the fixture serves the live population and refuses every observation
  after `release`; the object, union, and schema factories carry their population through
  `properties`, `variants`, and an advertised key list, plant the `invalid` defect, and raise the
  fixture's own exact `reason` for a read outside the advertised child.
- **hostile sources** — the revoked pair refuses every observation including the array brand; the
  throwing getter, hostile keys, and throwing prototype each refuse exactly the observation they
  name and nothing else; the stateful getter drifts one way after its first read and the unstable
  array advertises through a non-enumerable `slice` what its indices do not hold; the
  native-maximum sparse array advertises `2 ** 32 - 1`, reflects only `length`, and records
  `value:`, `descriptor:`, and `membership:` probes as it refuses each.
- **structural fixtures** — cyclic record and array, sparse array holes, non-enumerable own member,
  null-prototype record, class instance; `buildDeepNest` alternates layers and lands on the leaf at
  the requested depth; `buildWideVocabulary` is ordered, distinct, and sized; the one-shot iterator
  is consumed once and the infinite one is self-iterating.
- **shape factories** — `buildDeepShape` nests one array level per depth; `buildSharedDagShape`
  binds one child into both properties and expands to `2 ** (levels + 1) - 1` emitted nodes under a
  non-sharing walk; `buildStaircaseShape` reaches the same child through an edge per level, each a
  level deeper; `buildCountedGraph` tallies one read per record visit and holds one record per
  shared slot, two per unshared one; `compositeShape` carries every kind at the flat level and
  wraps the previous level per depth; `createShapeValidationCase` plants the defects in the caller's
  order and owns its graph; `SHAPE_SEPARATIONS` keys every row by the kind it names in the position
  that kind permits, and the witness-free kinds are `json`, `null`, and `raw`.
- **sample corpora** — `SOUNDNESS_SAMPLE` is frozen and carries signed zero, `NaN`, both
  infinities, a bigint, a symbol, a function, `undefined`, `Map`/`Set`/`Date`, a cyclic record, and
  a nest deeper than `INFER_DEPTH_LIMIT`; `soundnessViolations` is silent for a sound pair and
  names `A@<index>` for a guard-valid input the parser refused and `B@` for an output the guard
  rejects; `validSamplesFor` and `invalidSamplesFor` answer disjoint non-empty sets per leaf kind,
  nothing for a container, and dispatch on the integer flag and the declared vocabulary.
- **report fixtures** — `buildTypeFault` builds the smallest well-formed fault, fresh and
  distinguishable per kind; `faultsToConstraints` projects a report in order, answering `undefined`
  for every non-constraint entry.
- **observation seams** — `ObservedShape` counts each observation and clears; `LateMutation`
  rewrites on every enumeration after the first and tallies walks; `ReentrantShape` performs the
  nested operation on the first read only and records its outcome, including a failing one.
- **schema and memo fixtures** — the present-but-undefined keyword, the genuine array root with no
  own keyword, the class-carried memo with real `WeakMap` and `Map`, and the complete two-child
  tree with one value draw per node.
- **guide comparison fixtures** — `DriftedMethods` carries a documentable and an undocumented
  name-keyed member; `SmuggledMember` is invisible to a name walk and reachable only through
  `SMUGGLED_KEY`.
- **roundtrip assertions** — `expectLockstep` and `expectJSONRoundtrip` drive a leaf and a
  composite declaration through and propagate the failure of an ungeneratable one rather than
  swallowing it; `compileWidenedContract` returns the compiled surface for a widened declaration,
  and its type-level claim is carried by this file's own typecheck; `Equal` and `Expect` answer type
  identity, with a mutually assignable non-identical pair as the control.

One host-varying property is deliberately not asserted, and the file says so where a reader meets
it: whether spreading the default `buildWideVocabulary` result into arguments raises a
`RangeError` depends on the stack budget, and a Vitest worker carries a larger stack than a plain
Node entry (it throws under `node --input-type=module`, and does not throw inside the worker). The
proof pins the size and the order; the suites that drive the vocabulary through the package own the
refusal.
