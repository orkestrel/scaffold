## Goal

Add a host-independent provider base to `@orkestrel/agent` core that owns every provider mechanic
up to the seams that are wire-specific, rebuild `@orkestrel/ollama`'s `OllamaProvider` on it, and
give a browser runtime a way to drive a provider through the developer's own server with a
custom token while the real credential stays on the server. `@orkestrel/supervisor` is context
only: it is read for its provider and relay patterns and is not written in this campaign.
