Read CSS custom property with optional -- prefix: elements:token, mailbox:token, scsr:token. elements/mailbox prefix then call style(); scsr inlines the prefix into the style() call.

Parse CSS color via probe element to RGBA: elements:rgba, mailbox:rgba, scsr:rgba. elements/mailbox appendChild and error `Could not parse color: ${color} (resolved: ${resolved})`; scsr append and error `Could not parse color: ${color} (${resolved})`. Channel math matches.
