### Clusters
Resolve interactive by role/name: workbench:resolveRendered (visibility/focus/enabled, no viewport requirement, exact getByRole) vs workbench:resolveAccessible (calls resolveRendered, scrollIntoView if outside viewport, throws if still outside).
Accessible activation: workbench:clickAccessible (resolveRendered + userEvent.click, exact name, no region) vs workbench:clickAccessibleWithin (region getByRole exact, inner role name exact:false, same reachability filter, userEvent.click) vs workbench:clickDisclosure (querySelectorAll('summary') by normalized innerText, no getByRole, userEvent.click).
Accessible field write: workbench:typeAccessible (click, Ctrl-a Backspace, keyboard with `{`/`[` escaped) vs workbench:fillAccessible (userEvent.fill entire string).
Vue component mount: workbench:mount (createApp(component, props), InjectionKey map provide, returns only idempotent cleanup) vs scsr:mountComponent (createApp render h(component, props), string+symbol provide, await nextTick, returns [container, cleanup]).
Vue setup/composable mount: scsr:withBootstrap (setup() assigns use(ref(element)), throws 'Expected composable result', caller-held cleanup) vs elements:mountSetup (setup() return value, optional silent errorHandler capturing then rethrowing, registerUnmount on BROWSER_UNMOUNTS) vs elements:withElement (mountSetup wrapping use(ref(element))).
Append-to-body node constructors: workbench:render (innerHTML string into div) vs scsr:createBootstrapElement (tag + class tokens) vs elements:buildElement (tag + attrs + text) vs router:createAnchor (<a href>, optional target/download).
Wait for animation frame: workbench:waitForFrame (one requestAnimationFrame). (Not the same job as Vue nextTick or microtask flush.)
Wait for Vue bootstrap ticks: scsr:waitForBootstrap (nextTick, optional setTimeout(delay), nextTick) vs elements:waitForBootstrap (nextTick, optional waitForDelay(delay), nextTick). Same name; delay backend differs (raw timer vs waitForDelay).
Microtask flush: scsr:flushPromises (two Promise.resolve only).
Poll-until helpers: scsr:waitForCondition (20 loops, predicate, flushPromises + setTimeout 0, throw message) vs scsr:waitForStream (20 loops, flushPromises only, throw 'Expected stream controller').
Dispatch Event on a node: scsr:dispatchBootstrapEvent (new Event(name, init), dispatch, return) vs scsr:dispatchCarouselEvent (new Event(name), defineProperty 'to', dispatch, return).
Construct pointer/drag events (no dispatch): elements:createDragEvent vs elements:createPointerEvent.
Synthetic mouse click: router:click (MouseEvent click composed/bubbling/cancelable, modifiers) vs router:safeClick (window once click listener records defaultPrevented then preventDefault, then click).
Set input value + input event: elements:inputField vs terrain:typeInput (same: assign value, dispatch bubbling input). terrain:commitInput is that job plus a bubbling change event.
