## Transformation

1. `mv src/server src/core`. Inside `src/core/*.ts`, change nothing except relative imports that
   named `server` (there are none expected; verify with grep).
2. `mv tests/src/server tests/src/core`. In the moved files and in every authored test file listed
   under Owned, rewrite `'@src/server'` to `'@src/core'`. Leave `tests/config.test.ts` untouched.
3. `mv configs/src/tsconfig.server.json configs/src/tsconfig.core.json` and edit it to the agent
   reference's form: `lib: ["ESNext", "WebWorker"]`, `types: []`, `rootDir: "../../src/core"`,
   `outDir: "../../dist/src/core"`, `include` over `../../src/core/**/*.{cts,mts,ts,tsx}`.
4. `mv configs/src/vite.server.config.ts configs/src/vite.core.config.ts` and rewrite it to the
   agent reference's form: import `srcCore` and `resolveWorkspacePath` from the root config,
   plugins `outputBoundary('dist/src/core')`, `environmentBoundary('src/core')`, and
   `declarationRollup({ project: resolveWorkspacePath('configs/src/tsconfig.core.json'), types: ['node'] })`;
   `build.lib.entry` at `src/core/index.ts`, `formats: ['es', 'cjs']`, the `fileName` callback,
   `outDir: 'dist/src/core'`, and the `rolldownOptions.external` predicate. Drop
   `rewriteCoreSpecifier` (a core face has no core specifier to rewrite).
5. In `vite.config.ts`: rename the exported `srcServer` to `srcCore` with the agent reference's
   body — label `src:core`, colour `magenta`, `include: ['tests/src/core/**/*.test.ts']`,
   `setupFiles: ['./tests/setup.ts']`, no `plugins`, no `lib`, no `outDir`, no `target`, no
   `platform`, `build: { emptyOutDir, sourcemap, minify: false, rolldownOptions: { onLog: enforceBuildLog } }`
   — and update the `projects` list and the import of `environmentBoundary`/`outputBoundary` (drop
   the ones the root no longer uses). Keep `conformance`, `service`, `distribution`, and every
   other project exactly as they are.
6. In `tsconfig.json`: `paths` become `"@src/core": ["./src/core/index.ts"]` and
   `"@orkestrel/ollama": ["./src/core/index.ts"]`.
7. In `package.json`: `main`, `module`, `types`, and both `exports["."]` branches point at
   `dist/src/core/index.{cjs,js,d.ts,d.cts}`; scripts `check:src` → `npm run check:src:core`,
   `check:src:core` → `tsc --noEmit -p configs/src/tsconfig.core.json`, `test:src` and
   `test:src:core` → `--project src:core`, `build:src` → `npm run build:src:core`,
   `build:src:core` → `vite build --config configs/src/vite.core.config.ts && npm run copy dist/src/core/index.d.ts dist/src/core/index.d.cts`;
   delete the `*:server` script names. Change nothing else in the manifest — not `version`, not a
   dependency, not `description`.
8. In `guides/ollama.md`, `guides/README.md`, and `README.md`: replace every `src/server` and
   `tests/src/server` path string with its `src/core` / `tests/src/core` form, and nothing else.
   Do not rewrite prose.
9. Run, in order, reading each result bare: `npm run format:check`, `npm run lint:check`,
   `npm run check`, `npm run build`, `npm test`. Fix only what the move itself broke. Then run
