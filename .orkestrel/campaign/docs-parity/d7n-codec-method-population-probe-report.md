# Codec method-population probe report

The unexecuted in-memory control is [probe-codec-method-population.mjs](../pass/probe-codec-method-population.mjs).

It reads Codec's real inventory through installed Test and composes the public Guide `Parity` with Codec's consumer options. It adds an in-memory Methods table without a Summary column, verifies parser population, compares the absent method against source reflection, and requires the public methods report to retain it. It prints the parsed group and active report categories.

The native suite has not run against the variant.
