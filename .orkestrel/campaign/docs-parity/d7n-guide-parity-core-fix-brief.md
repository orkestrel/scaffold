## Contract to implement

Define types before implementation. Keep readonly properties and collections.

- DriftCategory derives from a frozen DRIFT_CATEGORIES containing summary and example.
  Drift requires category. computeDrift takes (key, category, guide, source), and
  findDrift supplies summary for Surface/Methods and example for titled fences.
  Update driftShape, isDrift, contract tests, callers, and guide examples atomically.
  Do not infer category from key text, array position, or replacement success.
- ParityOptions carries files, entries, modules, languages, language, and optional
  pitch. Use the existing inventory, ManifestEntry, and GuideModule contracts.
  modules maps self specifiers to source scopes; languages lists admitted fences;
  language selects executable-example/import inspection. A named ParityPitch holds
  readme and spec inventory keys. The caller chooses these, never the engine.
- ParityRow carries entry, guide, and source. Parity.rows() returns these shared
  readonly views for package-specific assertions; missing specs remain findings.
- ParityFinding carries spec and preformatted text. ParityReport carries readonly
  finding arrays named input, surface, methods, links, tests, fences, examples,
  imports, drift, and pitch. Do not store another rule label duplicating its bucket.
- ParityChange carries path and content. ParityRewrite carries readonly changes
  and findings. Changes contain only changed texts after full path-keyed accumulation;
  findings describe unresolved requested rewrites against the accumulated result,
  including the relevant spec, category/key, compared sides, and reason in text.
- ParityInterface exposes rows(), inspect(), and rewrite(direction). Direction is
  guide or source, naming the destination; source authority writes guide summaries
  and examples, guide authority writes source summaries and examples. Do not add
  side-manager forwarding objects, a launcher, a filesystem boundary, or Vitest peer.
  createParity returns the interface and Parity is exported through the sole barrel.
