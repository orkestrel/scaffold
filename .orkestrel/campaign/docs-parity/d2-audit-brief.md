## Claims (verdict per claim: PASS, FAIL with `file:line` evidence, or CANNOT RULE with what is missing)

1. **The renderers.** `renderSurface` renders a `Name | Kind | Summary` table one row per symbol (name as a code span, kind as the keyword, an absent summary as an empty cell); `renderMethods` renders the H4 code-span heading and its `Name | Summary` table; `renderExample` renders the heading of the title (none for an untitled example) and a fence with the language and code; each renders through `renderMarkdown` over a node the function builds and is a pure function of its argument; and each reads back through its reader (`extractSurface`, `extractMethods`, `extractFences`) to the entries it rendered, with the section-heading prefix the report records.
2. **`replaceCell`.** For a Surface key (`computeSymbolKey`) or an `Owner.member` key, exactly the located row's `Summary` cell changes and every byte outside the located table's span is unchanged; a miss (no row carries the key, no `Summary` column, no recorded span) returns `undefined` and never throws; a summary the row already carries returns the input byte for byte.
3. **`replaceFence`.** The first fence under the heading of the given title is replaced (language and body), every byte outside the fence's span is unchanged, a title no fence carries or an untitled fence returns `undefined`, and a later fence of the same title is outside the pairing (the `findDrift` rule).
4. **`replaceSummary`.** Over a raw doc block with its indentation and markers, the description paragraph (text before the first block tag) is replaced, the blank separator and every tag line survive byte for byte, the indentation and markers are preserved, the result stays inside `WIDTH`, the new description reads back through the comparing reader, and the identity case is byte-stable over every block the checkout ships (the report's `0 of 151`).
5. **`replaceExample`.** Only the `@example` carrying the given title is rewritten (language and code); an untitled or differently titled tag is untouched; a block with no such tag returns unchanged; a tag-shaped line inside the current body is not read as a tag; a block naming no title replaces an untitled tag.
6. **The leaves and the rewiring.** Each leaf is an exported pure function with a test and a guide row; names follow `{verb}{Noun}` for helpers and single words for constants; `buildCell` is the inverse of `extractCellText`; no leaf is a superfluous wrapper; and `extractSurface`, `extractMethods`, `extractFences`, and `normalizeComment` keep their behaviour after the rewiring (the tip's cases green, no case weakened).
7. **Types and boundaries.** No type changed and none was needed (the miss shape `undefined` follows `.claude/rules/typescript.md`); nothing in `src/**` reads or writes a file; `Source` and `Guide` are untouched; no dependency was added.
