## Decisions

- Capture full local manifests and lockfiles, source and branch readings, and full
  npm view output before graph reconciliation. Root refreshes origins in a separate
  recorded operation; the read-only carrier does not fetch.
- Preserve the original command arguments, timestamps, cwd, process code, signal,
  failed, expired, aborted and truncated values. Store stdout and stderr without
  parsing or changing their contents. The execute primitive returns decoded strings;
  encode those strings as UTF-8 and state that boundary. Copy source files as bytes.
- Record capture failures explicitly and retain successful evidence. Interpret JSON,
  identity, package health, graph edges and completeness outside the carrier. Do not
  implement the objective proposal's parse/health facts inside the carrier.
- Capture file bytes and Git readings again after the read-only phase. Compare those
  readings during checking. A moving checkout invalidates its capture; it does not
  authorize restoration or erase another package's evidence.
- Keep lock, installed, nested, tarball, packed-manifest and gate receipts in each
  visit. Any changed final dependency edge requires updated graph reconciliation
  before the affected dependent proceeds.
- Stop collection on expiry or abort and retain the partial transcript. Root must
  establish quiescence before another run. Report Windows tree cleanup as unobserved;
  do not add a supervisor or derive a tree-outcome field from native exit.
- Use the public layer helper only where its actual input semantics fit the supplied
  evidence. No live catalog call is required merely to corroborate a complete local
  graph, and no optional or tooling edge may disappear through its catalog schema.

Root's standard npm view and npm ls readings are retained in
d7n-capture-command-reading.md. Their successful exits do not certify fleet coverage
or installed-path completeness. The reported PowerShell file encoding prevents a
false native-byte claim in the successor carrier.

Do not carry unsupported predecessor findings into the new boundary: changed source
line numbers alone do not prove changed test semantics; a helper-prefix list alone
does not forbid another descriptive helper; and a source-parser suggestion cannot
override the analyzer prohibition. Annotate prose counts in retained reports without
reopening their units.
