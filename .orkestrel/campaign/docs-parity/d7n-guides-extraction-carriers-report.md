# Extraction carriers

The `run-parity-gates.sh`, `pack-parity-guide.sh`, `install-parity-guide.sh`, `inspect-parity-guide.mjs`, and `mirror-parity-guide.mjs` carriers are ready.

The package install and pack carriers retain their exit state on success or failure, apply the required timeout, and reject unsafe evidence labels.

`bash -n` accepted the shell carriers. `node --check` accepted the inspection and mirror carriers.

Do not execute the carriers. Root owns carrier execution and receipts.
