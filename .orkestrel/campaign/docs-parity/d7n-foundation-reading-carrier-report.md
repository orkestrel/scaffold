# Foundation release-reading carrier report

The unexecuted reader is [read-foundation-release.sh](../pass/read-foundation-release.sh).

It retains raw npm registry packuments with command exit and separated output. It records each canonical repository's fetch, Git branch, commits, ancestry result, status, and package manifest. A dirty or ancestry reading remains evidence. A failed registry or fetch reading retains its exact result and stops the carrier.

The carrier does not read credentials or modify product paths.
