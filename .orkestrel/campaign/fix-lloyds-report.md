Two measurements were needed to make Escape work, both recorded here because they are surface facts
rather than test plumbing:

- Bootstrap hands the dialog its focus only when the opening fade completes — measured at 338 ms in
  this runner. A key pressed before that lands on the body, which is not inside the modal, so
  Bootstrap's own dismiss handler never fires. `closeReference` waits for the focus first.
- Bootstrap hides a modal in stages: the dialog's `display` first, then the backdrop's fade, and only
  in the last stage does it hand the page its scrolling back and refocus the opener. An act performed
  before that stage is taken back — a Tab traversal was walked over and an Enter landed on the
  opener. `closeReference` waits on `readStyle(document.body, 'overflow')` returning.

The focus reading needed correcting once: `readFocus()` on `body` returns the page's own words, so a
hint test alone passed with focus still on the page. The rail's brand line is what separates them.
