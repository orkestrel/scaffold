Narrow isInstance to the constructor's instance type and release 0.0.18

`isInstance` now takes the constructor constraint `instanceOf` carries and narrows `value` to
`InstanceType<C>`; its intersected return type narrowed to `object` and over-narrowed the false
branch. The body is unchanged, so runtime behaviour is unchanged. Compile-time proofs pin the
narrowing for a concrete, an abstract, an argument-taking, and a generic class, the false
branch of a nullable base against a derived, a structurally identical, and an optional-member
subclass, the parity of the parameter constraint with `instanceOf`, and the refusal of a
non-constructor, the bare `AnyConstructor`, and a `Function`-typed value. The remark states the
narrowing, the constraint, the last-construct-signature reading, the subtype rule of the false
branch, and the `Object` limit. Every fleet consumer wraps the guard in an explicit predicate or
a boolean, so none changes. Audited by Opus 5.5 and Astra on swapped lanes and the checker over
three rounds, with the Orchestrator's constraint-mutation and false-branch controls red.
