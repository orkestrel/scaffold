## Findings outside the claims

**A. `tests/src/core/helpers.test.ts:3288` — the test title still carries the exact wording this round removed from the prose, so the tree now states one fact two ways and states it wrongly in the surviving copy.**

The title reads `reads a hand-rolled shape's pattern accessor twice per call, for the presence test and for the rebuild that names the limit`. Its stated subject is "a hand-rolled shape", unqualified.

Falsifying input, from the Orchestrator's own probe record (`readcount-cases-u3final.out`, "min only (accessor answers undefined), omitted argument: 1"): `createStringFaults({ type: 'string', min: 4, get pattern() { reads += 1; return undefined } }, 'abc', [])` reads the accessor once. That shape is hand-rolled, so the title's property is false of it. This is the same overstatement, with the same defence — the trailing clause names both reads, therefore the condition is implied — that the U3i lane rejected for the prose sentence at `src/core/helpers.ts:1930-1933`, whose enumeration was more explicit than this title's. The U3i lane confirmed this title on that defence at its claim 2 and then conditioned the confirmation: "Carry the claim-1 correction into this title if the fix changes the wording, so the title and the prose stay one vocabulary." The fix changed the wording; the carry did not happen, because the U3j brief's acceptance criterion 5 asserted the title was already "bounded to a declared pattern". It is not.

Why it matters beyond wording: `grep` for `twice per call` across the tree returns this line and nothing else, so the superseded vocabulary now survives in exactly one place, in a test title — the artifact `.claude/rules/tests.md` § Discovery and adequacy audit makes a reader trust for what the assertion covers. `AGENTS.md` § Design laws, "One concept, one term", is the rule this breaks.

What right looks like — smallest correct fix, keeping the pin and its reading untouched: rename `:3288` to `reads a hand-rolled shape's pattern accessor twice per call when the shape declares one, for the presence test and for the rebuild that names the limit`. Change no assertion; the body's shape declares a pattern, so it remains the declared-pattern case of the rule the prose now states.

## Referral to the Orchestrator (objective lane not running this round)
