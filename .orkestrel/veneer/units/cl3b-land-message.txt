Bind the Content colours the record measured (CL3b)

The text tags that read a muted colour and the code members that read a
raised surface now read tokens rather than inheriting. `--vn-text-muted`
lands from the calibration record, `--vn-surface-raised` takes the
record's own reading, and the code surface moves from an expression in
the theme emitter into the theme maps beside its siblings. The monospace
token becomes a pair, a base stack and the shorter one the variable tag
renders, which the registry's path law makes a group. The code block's
rhythm takes a token of its own.

The dark theme's mix anchor is now a literal rather than a read of the
raised surface. The two were one token and are two values: the anchor is
what every dark role tier was calibrated against, and the raised surface
is a Content reading. Every dark role border tier resolves to the value it
had before this change, measured before and after.

The corner radii the code, keyboard, and preformatted surfaces ship are
pinned by their proofs, so deleting a radius reddens.

Every gate exits 0 on managed Chromium and Edge. The audit is recorded in
scaffold's `.orkestrel/veneer/cl3b-audit-verdict.md` file.
