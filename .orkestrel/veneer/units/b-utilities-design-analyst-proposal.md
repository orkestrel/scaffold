## Units

Propose mechanism units with exclusive file ownership, followed by serial integration and independent verification. The proposal uses the inspected `87ff1d0` tree; the working tree was clean.

The terrain needs these corrections before dispatch:

- D39a governs priority: the inventory omits declaration priority, and `tests/conformance.test.ts` compares priority against Bootstrap’s compiled CSS. Departure cells remain value-only.
- The margin stems are `m`, `mx`, `my`, `mt`, `me`, `mb`, and `ms`; padding uses `p`, `px`, `py`, `pt`, `pe`, `pb`, and `ps`. Size work from those sets, rather than the terrain’s arithmetic.

## Family rulings

The family record needs the following numbered rulings.

1. **Use the pinned release as the declaration contract.**  
   Option: reproduce the recorded selectors, values, conditions, and priorities with accounted token substitutions. Cost: detailed comparison and responsive proofs. Recommendation: adopt this option; do not generate optional negative-margin output or substitute a generic utility framework.

2. **Keep utility and helper priorities distinct.**  
   Option: preserve Bootstrap’s declaration-by-declaration priority. Cost: helper and custom-property cases need separate assertions. Recommendation: ordinary utility properties retain Bootstrap’s importance; local variables and `css-var` declarations remain normal; helpers retain their recorded priorities.

3. **Keep the existing gap partial intact.**  
   Option: extend `_gap.scss`, or split gutters from CSS gaps. Cost of splitting: file moves, proof moves, and ledger/documentation churn without changing the token contract. Recommendation: extend the existing partial, retaining gutter tests and the density-independent gap scale.

4. **Ship unlisted utility entries under their recorded keys.**  
   Option: ship them here, defer them, or exclude them. Cost of shipping: additional proofs and specimens within existing mechanisms. Recommendation: ship overflow axes through FLOW; text-decoration through TYPE; text/bg/border opacity and text-background helpers through PAINT; pointer-events through ACCESS. Retain the shipped link implementations and verify their state coverage.

5. **Close compound inventory keys explicitly.**  
   Option: integrate all contributors together, or use temporary selector deferrals with named owners. Cost of premature key closure: missing declarations hidden behind a `shipped` row. Recommendation: integrate SPACING with ACCESS for `pe`, and TYPE with PAINT for `text`; use explicit temporary deferrals only when separate landings require them.

   Option: reuse existing matching tokens and compatibility variables, or introduce utility-specific tokens. Cost of token expansion: another public surface and token-parity obligation. Recommendation: add no token in this family. Use this binding policy:

   | Utility mechanism | Binding |
