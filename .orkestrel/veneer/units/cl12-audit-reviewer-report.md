# CL12 audit round 1 — subjective lane report

## Rulings on the claims

report. The exceptions follow.

- **Claim 4, the range-row claim — CONFIRMED as narrowly true.** The added literal-row convention is
  right and is not two conventions in one table: the added table sits directly above another that
  already uses one literal row per token, and the range rows are the local minority. On "a range row
  cannot be read by a completeness check", literally true for the check the unit proposes, and the
  report qualifies it immediately with the alternative it refuses. The claim is not overstated. *(The
  objective lane refuted this more broadly by executing a range expansion; the Orchestrator sided with
  the objective lane on the general claim while this lane's narrower reading stands.)*
- **Claim 13 — REFUTED in part.** "Ran by instrument" and "populations derived from the tree" hold, and
  the population derivation is the best thing in the unit: the sweep builds its sets from the cascade's
  own declared properties and the registry, then asks which the guide fails to name, which is why it
  found the two tokens the record missed. Two defects in the "named and retained" half: **the
  instruments are not retained** in the campaign folder, which is the Orchestrator's step; and **one
  instrument cannot have produced the result attributed to it** — the ledger instrument prints a row
  only when an obligation carries both a backticked class and a backticked token, and the pre-edit
  false row carried no token, so the reported discovery account is not reproducible. The correction
  itself is verified true, so this is an evidence-honesty defect rather than a product defect.
- **Claim 16 — CONFIRMED with a carried finding.** The terrain correction is right and flagging it was
  right. The gap: the terrain record's own section still names the smaller number while the same file
  carries a correction for a different claim, so a successor opening the record meets the false number
  with no pointer.
- **Claim 19 — CONFIRMED on ownership; the recommendation's cost line is incomplete.** Leaving the gate
  to a successor is correct, and refusing the parser alternative is correct. But the cost line
  under-enumerates: it omits the composite rows, and four registered tokens appear **nowhere in the
  guide at all**, not backticked and not bare, because they are written only as a suffix fragment
  inside a base-name row. A successor taking the option verbatim discovers this mid-unit.
- **Claim 23, scope honesty — REFUTED narrowly**, on the ledger attribution alone. Every edit the
  report describes is in the diff and nothing in the diff is undescribed.

## Findings beyond the claims

**24. The container-cap sentence misstates the cascade. THIS FORCES A FIX ROUND.** The added paragraph
says one width caps its own family from its own boundary upward. The partial appends on each pass, so
every rule names its own name **and every narrower one**, and the built cascade shows exactly that. The
narrow container therefore reads its own width only between the first two boundaries, and above the
widest it reads the widest width. **Failure scenario:** a consumer sizing a layout reads that the narrow
container is capped at its own width above its boundary, and measures the widest width at a desktop
width. **Why it matters beyond the number:** this is the only prose explaining how the five new tokens
apply, and the round's stated objective is that no sentence claims a reading the tree does not produce.
A sentence added under that objective that a reader cannot act on is the defect the round exists to
remove. The lane supplied a corrected sentence.

**25. The deferred-names reason rests on a half-true premise. Fold into the same round.** The added
sentence says those names are Veneer's own rather than official ones; the table's first row is a
standard CSS property. The operative fact is true and stronger — none of those names is in the pinned
inventory the presence scanner checks against, which is precisely why the other table's reader would
refuse them.

**26. The tokens section uses two shorthand conventions it never declares.** Range rows and composite
rows cover members they do not spell, and the section never says so, so a reader cannot tell "covered by
shorthand" from "absent". **That ambiguity is the condition the missing rows grew in.** Does not force a
round; carried by the successor that lands the completeness gate.

**27. The mirror instrument proves a weaker statement than the report makes from it.** It maps partials
and proofs to their base names and compares the two sets, while the report and the guide both claim
"at the same relative path". A proof moved between directories leaves the base-name sets unchanged and
the claim false. Does not force a round — both trees were walked by hand and the mirror holds today.
Carried by whichever unit next runs that sweep.

**28. Both record corrections live only in the report.** The terrain record and the brief each still
carry their uncorrected claim, and the successor-brief rule forbids editing either in place. A successor
reading either cold inherits the error. Right looks like carrying both corrections into the verdict and
into the successor brief, or appending a dated correction block to the terrain record in the pattern it
already uses.
