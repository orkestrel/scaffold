## Obligations

### Obligation 1 — one frame grammar, aligned stems

Fix the filename law in the registry types and `expandCaptures`' inputs so every frame's name is
`<scenario>--<theme>-<viewport>[-<step>]` with the mode in the theme token and the project never
in a suffix; align each stem with the Elements portfolio's stem for the same subject where one
exists (the retained observations name them), and record the alignment table in the guide's
§ Tests capture paragraph. A stem that maps to nothing on the Elements side is named as Veneer-only
there.

### Obligation 2 — whole specimens with their background

Register the link key's frame over the whole `Role links` specimen (all nine anchors) with the
specimen's background, never a single anchor's crop, and do the same for every element frame whose
specimen holds more than one element. Where the frame must sit within the 900 px element bound,
stage the pane so the specimen fits, through `stagePane` and `releasePane`. Record in the guide the
bounded comparison (finding 5: Bootstrap's frames are of a blank page carrying the specimen alone;
Veneer's are lifts from the showcase) as the stated limit of side-by-side reading.

### Obligation 3 — per-specimen accessibility artifacts

Write, beside each specimen frame, that specimen's `describeTree` and `describeFocus` output as its
own artifact (one text file per specimen and variant, named by the same grammar with an
`accessibility` step), while keeping the per-variant page tree the manifest carries. Fix the mode
strings inside the focus-ring, contrast, pointer-paint, and journal readings so the 390 variants
record their own name rather than `light-1280` and `dark-1280`.

### Obligation 4 — the pixel guard and the sampler

Run the frame-variation guard over every written frame outside the capture flag wherever a frame
exists on disk (skip only when the portfolio wrote nothing, and say so in the case title), and
replace the origin-pixel comparison with a declared sampling region: the sampler takes the region
it compares against as an argument (an element's box in frame coordinates, read through
`getBoundingClientRect` at staging time), and the guard reports the fraction of pixels in that
region that differ from the region's first pixel. Where `readFrame` supplies the reading the guard
needs, use it and delete the local decoder.

### Obligation 5 — the caption opt-out specimen and the helper contract

Add to `TABLE_SPECIMENS` the specimen that carries the F6 caption opt-out class, register its frame,
and prove it in `TableSection`. Establish the helper-key subject contract: every registry key names
the specimen region that is its subject, the registry proof asserts that region exists in the
specimen tables, and the key the **Unknowns** identify is either given a subject region in the
showcase (through `constants.ts`) or removed from the registry with the removal recorded in the
report for `B-UTILITIES` to supply.

### Obligation 6 — re-shot Button frames

Re-shoot every Button frame under the corrected grammar with capture on, and record in the report,
per frame, its `readFrame` size, its bottom-row colour, and its variation reading. A frame whose
reading exposes a Button defect is reported as a finding for the Orchestrator, never fixed here.
