Ship the font, font-size, font-style, font-weight, and line-height keys

The font keys ship in the utilities layer through the utility mixin in one breakpoint walk, every
declaration important as the release writes it: each size class reads the heading size token its level
names, so a retuned size token moves the size class and the heading class together, the weight and
line-height classes read their tokens, and the monospace class reads the monospace stack. The Type
region gains the font specimens beside the typography it already renders. The case tables live in the
setup file, frozen and bound to the inventory by derivation, each named mutation turns its case red,
and the guide carries the font section, its compatibility and ledger rows, and the Tailwind names.
