## Findings outside the claims

16. **`guides/veneer.md:160` teaches an alpha form that paints nothing.** The line reads "for a consumer writing `rgb(var(--vn-color-primary-rgb) / 0.5)`". The triplet is comma-separated (`_tokens.scss:18` `'primary-rgb': '8, 65, 234'`), so the declaration substitutes to `rgb(8, 65, 234 / 0.5)`, which mixes the legacy comma syntax with the modern slash alpha and matches neither `rgb()` grammar; the engine drops the declaration and the element paints nothing. The same section's opener (`:86`) and the customization prose (`:276`) both use the working `rgba(var(--…-rgb), α)` form, and so does the shipped cascade itself (`_tokens.scss:206-219`), so the guide hands the reader two spellings for one job and the deviant one is the broken one. Failure scenario: a consumer copies line 160 for a translucent brand fill and gets an unpainted background with no console error. Right: write `rgba(var(--vn-color-primary-rgb), 0.5)` at `:160`, matching `:86`, and put the claim under the fence `tests/src/styles/integration.test.ts` already executes, so the form is asserted rather than asserted-about. **Forces a fix round.**
17. **`guides/veneer.md:321-329` files a declared feature under "Deferred names".** The section opens "These names are not declared in this release. Each one lands with the first consumer that reads it, and each is named here so a consumer does not look for it" (`:323-324`), and the next paragraph (`:326-329`) documents `interpolate-size: allow-keywords` as declared on the document element and read by `tests/src/styles/elements/html.test.ts:6`. Failure scenario: a consumer scanning § Deferred names for what Veneer lacks reads the opening sentence, concludes `interpolate-size` is absent, and declares it again on `html`, duplicating `_html.scss:5`. Right: move the `interpolate-size` paragraph out of § Deferred names — the elevation-and-motion neighbourhood or § Departures both hold it — and leave the section to names the release does not declare. **Forces a fix round.**
18. **`tests/src/styles/integration.test.ts:17` claims a coupling nothing enforces.** The TSDoc ends "so changing the fence changes this string". `RECIPE` (`:19-28`) is a hand copy of the `### Customization` fence, that fence carries no `@example` title, and `tests/guides.test.ts` compares only titled examples and `Summary` cells, so editing the guide fence leaves this proof green against the superseded recipe. This is the round-1 transcription finding restated in weaker words. Failure scenario: a successor changes the fence's fill and the proof keeps certifying a recipe the guide no longer shows. Right: write the sentence as the instruction it actually is ("change this string with the fence"), or give the fence a title and assert it against `RECIPE` so the coupling is real. **Required; rides with the same round.**
19. **`src/styles/_tokens.scss:219` puts one shadow rung outside the elevation factor.** `--vn-shadow-1` through `-3` scale every length by `var(--vn-factor-elevation)` (`:204-218`); `--vn-shadow-inset` does not. The guide calls that factor "the neutral multiplier of the shadow scale" (`veneer.md:107`) and says "A factor takes effect where the scale it multiplies is declared" (`:110`), and `src/core/constants.ts:206-211` puts `inset` in the same `shadow` group as the numbered rungs, so both the registry and the guide present one scale. Failure scenario: a component painting `--vn-shadow-inset` beside `--vn-shadow-1` on a page that sets `--vn-factor-elevation: 2` renders mismatched depth. Right: scale the inset with the factor, or say in the elevation row that the inset is retained outside the scale and why. **Bound.**
20. **`guides/veneer.md:88` overstates the `Source` convention.** "Each table's `Source` cell names where that row's value comes from" is false of the tier table (`:150-154`, columns Tier / Light / Dark / Alias) and of the departures table (`:287-302`, Token / Veneer value / Bootstrap value), both inside § Tokens. Failure scenario: a reader reaches the tier table looking for the `Source` cell the section promised and finds none, then cannot tell whether the percentages are measured or retained — a fact the prose at `:156-157` carries instead. Right: scope the sentence to the reference-map tables, or say what fixes a value in the tables that carry no `Source` column. **Bound.**
