## Findings

**19. The pixel guard is unreachable in the standard gate chain**, running only under the capture flag.
A later change breaking placement would leave the ordinary suite green. Inherent rather than introduced
— it reads written files, which exist only in a capture run — and the report names the skips. Recorded
as a bound on what the ordinary chain proves; carried by whichever unit next owns the portfolio layer.

**20. The sampler measures against the origin pixel rather than against uniformity.** A frame blank
everywhere except its origin pixel passes, and a frame and its mode twin can report the identical
fraction. No producer exists in this harness, and a genuinely uniform frame returns zero whichever pixel
is the reference. Closing it means counting distinct values rather than differences from one reference —
a successor's choice rather than a defect shipped here.
