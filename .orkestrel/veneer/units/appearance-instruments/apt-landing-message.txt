Scale headings and size classes below 1200px as Bootstrap's responsive font sizes do

The user's appearance ruling (P8, option B) keeps the 14px base and the 600
heading weight, and scales the headings, the .h1 to .h6, .fs-1 to .fs-6, and
.display-1 to .display-6 classes, and the fieldset legend below the xl
boundary. The fluid-size function reproduces Bootstrap 5.3.8's rule over a
size token: a size above the 1.25rem floor gives up part of its excess over
the floor in proportion to the viewport's distance below 1200px, so a retuned
token scales too, and from the boundary on the size is the token itself. The
font-size mixin writes the fluid value and its xl cap; the .fs-* caps sit in a
trailing block with !important, as the release writes them. The proofs compare
each size at 390, 1199, 1200, and 1280 pixels with an independent oracle,
retuned tokens included.
