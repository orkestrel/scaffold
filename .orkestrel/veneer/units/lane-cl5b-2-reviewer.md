## Findings beyond the claims

**9. Whitespace at the interpolation boundary still separates two spellings — does not force a round.** `tests/setupConformance.ts:301-304` folds a run to one space but nothing trims at `#{` and `}`, while outside an interpolation the `^\s*`, `\s*:\s*`, and `.trim()` at `:314-:316` remove boundary whitespace entirely. So `--vn-color-#{$role}-base` and `--vn-color-#{ $role }-base` compare unequal. Failure scenario: a later unit duplicates a block and writes one copy with a space after `#{`; the sweep reports nothing. This is a false negative only, it is the residue of round 1's Objective 12 rather than a new defect, and it is unreachable in the tree today — every `#{` under `src/styles` is written tight. Note for the Orchestrator: brief 3's acceptance criterion 2 reads "two spellings of one interpolation differing only in internal whitespace compare equal", which is met for the pinned run-length pair and not in general. Right looks like skipping leading whitespace after `#{` and trailing whitespace before the closing `}` in the same branch. Carry it as a bound on the next unit that touches the sweep, not as a reopening of this one.

**10. Path normalization corrupts a POSIX filename holding a literal backslash — does not force a round.** `tests/setupConformance.ts:274` rewrites every `\` to `/`, and `:284` reads the file back through the normalized string, so a partial named `_a\b.scss` on Linux or macOS is reported as `_a/b.scss` and then read from a path that does not exist. The failure is a loud `ENOENT` rather than a silent miss, the population is authored SCSS partials, and Windows cannot create such a name at all. Right looks like keeping the native path for the read and normalizing only what is reported.

**11. The interpolation counter has no ceiling guard matching the parenthesis floor — does not force a round, pre-existing.** `tests/setupConformance.ts:294-300`: a `#{` whose `}` never arrives in the token stream leaves `interpolation > 0`, and the next block-opening `{` increments it further at `:295` instead of opening a block, so the partial contributes no blocks with no diagnostic — the exact shape round 1's Objective 13 named, in the other counter. Unreachable in compiling SCSS, because Sass rejects an unclosed interpolation before the sweep would matter, and this is round-1 code the fix round did not touch. Record it as a bound, not a repair.
