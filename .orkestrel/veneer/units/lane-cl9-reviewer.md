Right looks like: add `@use '../tokens';` beside the existing `@use '../mixins' as *;` at `:1`, delete `:96`, and write `@each $role in tokens.$aliased {` at `:97`. This changes no emitted byte, so it re-runs rather than re-derives the gates.
