Write the down-walks of the modal and table families through one ramp-down mixin

The breakpoint-each-down mixin walks the breakpoint ramp downward: its zero entry emits unwrapped as
the unsuffixed rule set every viewport receives, and each named entry follows in ramp order below its
own boundary through the breakpoint-down mixin. The modal fullscreen classes and the responsive table
wrappers write their rule sets once through it, and the built stylesheet is byte-equal to the one the
partials wrote before. The offcanvas partial keeps its own walk, because the release writes each
responsive panel's below-boundary and at-and-above blocks together and the bare panel after all of
them; its comment states that order. The mixins proof reads each named fixture specimen below, at,
and above its boundary, so a walk written upward reddens it. The guide states the mixin beside the
other breakpoint mixins, and its table section names it.
