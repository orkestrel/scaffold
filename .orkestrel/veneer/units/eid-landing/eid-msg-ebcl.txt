Compare each button form with the release's through one reader, in its partial's proof (E-ID-BUTTON-CLASSES)

readFormDifferences in tests/setupBrowser.ts mounts a class's button form and
its counterpart in the Veneer document and in a shadow root holding the
release's stylesheet, drives each state with real input, checks each state's
entry, and returns each cascade's map of differing longhands. It refuses a state
list that reads rest after another state or disabled before one. The .btn proof
and every button-reboot proof compare the Veneer map with the release map, so a
user-agent default that moves both cascades cancels (the Chromium 153 row's
shape), and each reboot case sits in the test file of the partial that writes
its include. BUTTON_FORM_DIFFERENCES is retired, the holder is
BUTTON_REBOOT_HOLDER_STYLE, and a case pins the reboot case table to the reboot
selectors.
