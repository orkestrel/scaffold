Ship the icon-link, ratio, and vertical-rule keys (CL10)

Three helper keys close the Content/layout family. The icon link ships its inline row, its
underline tint and offset, its icon combinator, and the hover and keyboard-focus shifts the
hover class arms. The aspect-ratio box holds its proportion through a pseudo-element whose
block-start padding is a percentage against the containing block's inline size, with the four
named aspects driven from a loop. The vertical rule reads the pre-declared border-width alias,
stretches to its flex line, and paints the current color at the opacity the official cascade
carries. One partial per key in the components layer, named for the inventory key each ships.

Nothing was deferred. Every selector the record carries under the three keys is in the built
cascade, and the guide's deferral table gained no row.

Four departures are recorded. The prefixed backface property is absent because the build's
targets emit the standard property alone, while the prefixed text-decoration alias ships
unauthored from the same build, so the key's two prefixed properties settle in opposite
directions. The icon's transition reads Veneer's motion tokens rather than the recorded
literal, so a consumer setting the motion factor to zero gets a still icon. The shift's inline
direction is physical, because no logical property replaces it and one byte stream serves
either writing direction. And the combinator names Bootstrap Icons' class, which nothing here
declares, so it matches nothing until a consumer brings the markup.

The proofs read the browser. The reduced-motion collapse is read under the staged preference
and the gated rule's own declarations are read from the built cascade beside it, so a collapse
written through some other property reports even where the resolved duration agrees. The icon
shift is read as painted distance rather than as a computed transform string: a transform
assertion on an outermost SVG element passes for every distance, which a mutation of the shift
distance demonstrated while the geometric assertion caught it.

The accounting grew to cover the three keys, and one round of audit forced a fix to what it
grew. The collector's selector boundary was ASCII-only, so it admitted a longer name whose
extension was non-ASCII or backslash-escaped, and it had been doing that for the grid, gutter,
and table prefixes since long before these keys. The boundary is now one shared continuation
rule refusing every CSS identifier continuation, with the caption class keeping its exact-name
restriction, and the control covers each refusal class rather than ASCII alone. Nothing false
had shipped: no such selector exists in the cascade or in Bootstrap's distribution, confirmed
by searching both and the record.

The same round moved a reader out of a test body into shared infrastructure, where an
exported helper carries its own proof; it distinguishes a reversed subtraction, a computed
offset substituted for the two rectangles, and a dropped parent translation. It also narrowed
a freeze assertion that had been running over string-literal tables, where a frozen check on a
primitive is unconditionally true and no mutation could fail it, and gave a normalizer
regression case its own rows so unrelated guide state can no longer redden it.

The emitted cascade did not move. The ratio loop lost its index reads and its list-module
dependency, and the built stylesheet and its right-to-left twin hash identically to the digest
before that change, reproduced by an independent build.
