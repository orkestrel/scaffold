## Findings outside the claims

The lane's own numbering; the verdict renumbers these into one sequence with the objective lane's.

- **26. The compatibility table now carries two granularities for one contract.** The earlier generated
  families carry a row per recorded family; the fixed-selector keys and these three carry a row per
  key. The brief asked for a row per family per key and the unit shipped per-key without recording the
  choice. Ruled: the per-key form is the better contract, because the presence scan obliges a
  component's entire recorded vocabulary from a single row and per-family rows add restatement without
  obligation. Settle the campaign on the per-key form and fold the earlier rows in when a unit next
  revises them. Does not force a fix round.
- **27. The ratio loop carries machinery Sass does not require.** Destructuring the pair in the `@each`
  header emits the identical cascade while removing both index reads and the list-module dependency.
  The grid partial also names its lists rather than inlining them in the header. Simplification law;
  no runtime failure. Does not force a fix round.
- **28. The icon-class selector list asserts an order it does not mean.** The equality runs over a Set
  filled in cascade document order, so reordering two selectors inside the hover rule reddens a change
  with no cascade meaning, reporting an ordering difference where a reader looks for a missing
  selector. Sort both sides, as the vocabulary collector does. Does not force a fix round.
- **29. The icon-link compatibility row is silent on its two value substitutions.** The link row sets
  the precedent by naming its substitution in the Notes cell. This key makes two: the underline reads
  Veneer's link triplet where the record reads Bootstrap's, and the transition reads the motion tokens
  where the record reads a literal. A consumer retuning Bootstrap's documented property moves nothing,
  because the token file declares that name over Veneer's rather than the reverse. Completeness rather
  than error; the partial itself is right and follows its own siblings. Does not force a fix round.
- **30. Only a name change surfaces, never a value change.** No test reads the guide's departures, and
  the presence scan compares names only. A future Bootstrap major that dropped the prefixed property,
  retuned the transition, or replaced the physical translate would leave all three bullets stale with
  every gate green. The campaign's standing shape rather than this unit's doing. Referred to the
  Orchestrator as a bound on the departures mechanism.
- **31. Two low-value observations.** The icon-link markup constant sits out of alphabetical position in
  the export list, which reads as a sorting error until you notice both sides sort. And the awaited
  resolved promise in the ratio case performs no layout flush, because the pixel reader forces layout
  itself, so it teaches an idiom that does not do what its position implies. Neither forces a fix round.

Nothing found contradicts a claim's operative substance, and no finding reaches the shipped cascade,
the proofs' falsifiability, or the scope.

Verdict: accept
