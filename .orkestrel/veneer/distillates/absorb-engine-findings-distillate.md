## Test infrastructure lessons

- A mutation instrument counts a kill only when the failing case's error names an assertion failure, and it reads every other failure as refused. `.orkestrel/veneer/engine/plan.md:184`
- A passed case counts as held only when the whole file run succeeds, because a sibling failure or an unhandled error can accompany the selected pass. `.orkestrel/veneer/engine/plan.md:184`
- A denylist does not define a kill: a `ReferenceError` after a rename killed rows in the same-direction audit, and a denylist admits a thrown `Error`. `.orkestrel/veneer/engine/plan.md:184`
- A fixed delay is a race because a showcase case that reads engine state immediately after awaiting the element's animations races the engine's settle; the proof rule keeps a delay inside 10 to 50 ms, and the Tooltip suite still waits 500 ms. `.orkestrel/veneer/engine/plan.md:181`; `.orkestrel/veneer/engine/plan.md:145`; `.orkestrel/veneer/engine/units/rebaseline-0925-tests.md:84`
- A Chromium build changes the reading: Chromium 141 never anchors on the baseline order, its initial `position-visibility` reads `always`, Chromium 153 defaults `position-visibility` to `anchors-visible`, and the sanitizer suite later read green on Chromium `141.0.7390.37`. `.orkestrel/veneer/engine/plan.md:37`; `.orkestrel/veneer/engine/plan.md:94`; `.orkestrel/veneer/engine/plan.md:144`; `.orkestrel/veneer/engine/units/rebaseline-0925-rulings.md:21`
- A plugin Proof cell is accepted when the named test file exists, which is a weaker check than a comparison with an independent Bootstrap recording. `.orkestrel/veneer/engine/units/rebaseline-0925-exit.md:54`
- The red-first obligation binds to the unit's base commit, which for the same-direction doors is `4b62bca`, rather than to the commit where the finding was read. `.orkestrel/veneer/engine/units/rebaseline-0925-rulings.md:13`
- `npm run test` chains its projects with `&&`, so one red skips every later project. `.orkestrel/veneer/engine/plan.md:180`
- The landing chain is `format:check`, `lint:check`, `check`, `build`, `test`, and `test:service`; its predecessor ran each project's gate and never `test` or `test:service`, and that predecessor is retired. `.orkestrel/veneer/engine/plan.md:179`
