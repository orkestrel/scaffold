1. **Construction, options, and lifetime.** `ScrollSpy` (`src/browser/ScrollSpy.ts`, one class plus imports) conforms to `ScrollSpyInterface` (`host`, `target`, `link`, `refresh`, `destroy`, the static `find`): the constructor refuses a non-`HTMLElement` host with `SCROLL_SPY_HOST_INVALID` carrying `readTag(host)`; resolves the `classes`, `attributes`, and `selectors` groups through `resolveVocabulary` with `SCROLL_SPY_OPTION_INVALID`; resolves `target` and `smooth` through `resolveOptions` over `{ smooth: SCROLL_SPY_DEFAULTS.smooth }` with `parseElement` and `parseBoolean`; resolves the `intersection` group as its own layer through `resolveOptions` over `SCROLL_SPY_DEFAULTS.intersection` with `parseRootMargin` and `parseThreshold` and the constructor's `intersection` group, so the constructor wins key by key and the attribute of a key the constructor omits still reads; re-validates the resolved margin and threshold and throws `SCROLL_SPY_OPTION_INVALID` carrying the key before any claim; claims the host; sets `#target` to the resolved target or the host's document body; binds the hooks through `bindEventMap` with `isScrollSpyEvent`; when `smooth` is `true`, binds a `click` listener on the target for the lifetime; destroys at once on an aborted `signal` with no refresh, else binds the abort and calls `refresh()`. Every refusal leaves the host unclaimed. `destroy` returns when already destroyed, aborts, disconnects and drops the observer, clears `#link`, releases the claim before restoring, and restores every `active` token the snapshot saved. Pinned by: "refuses a group value, a host attribute, and an intersection value that fail validation, before claiming the host", "refuses an invalid host and a second owner, then permits reconstruction after destruction", "reads its target, smooth scroll, margin, and threshold from the host attributes, the constructor winning per key", "destroys the scrollspy when its signal aborts, and at construction when it arrived aborted, observing nothing", "restores every link it wrote on destruction, keeping consumer edits, and observes and writes nothing more", "binds only engine-shaped events to its hooks", each with its instrument rows.

2. **Refresh and the observer.** `refresh` returns when destroyed; disconnects the previous observer; reads every `[href]` `HTMLElement` inside the target and, through `#section`, keeps a link whose `hash` (read from an `HTMLAnchorElement` or `HTMLAreaElement`, else empty) is non-empty, that carries neither the `disabled` token nor a `disabled` attribute whose value is not `false`, whose decoded fragment (`decodeURI`, a malformed escape refusing the link) names, through `host.querySelector` with `CSS.escape`, an `HTMLElement` inside the host whose `checkVisibility({ visibilityProperty: true })` is `true`; rebuilds the section-to-link and link-to-section maps; constructs an `IntersectionObserver` whose root is the host unless the host's computed `overflow-y` is `visible` (then the viewport), with `rootMargin` the resolved margin and `threshold` a copy of the resolved list; observes each kept section. Each refresh reads `overflow-y` again and replaces the observer, and a delivery of the replaced observer no longer holds its change (`#holds` compares `#observer`). A link added, removed, enabled, or disabled after a refresh counts from the next. Pinned by: "observes no link without a fragment, no disabled link, and no hidden section, and re-reads the links at refresh", "writes, tests, reads, and matches only the replacing values when every group is replaced", each with its rows.

3. **The delivery rule and its doors.** `#deliver` returns unless it holds (live, observer current); reads the scroll position of the root element or, for the viewport, of the host document's `documentElement`; `down` is that position not less than the previous one; then per entry with a known link: a leaving section clears `#link` when it was that link and removes the link's `active` behind the door (`#apply(observer, [], link, false)`), returning when the door fails; an entering section proceeds only when `down` equals (`offsetTop >= #top`), records `#top`, and activates behind the door, returning when it fails; when `down` and the position is zero, the first activation ends the delivery. `#activate` writes nothing and returns `true` when the link is the last selected and still carries `active`; else records `#link`, removes `active` from the target and from every `[href].active` `HTMLElement` inside it, each behind a door reading only the lifetime and the observer; adds `active` to the link behind a door that from then on also requires the link to carry it; adds `active` to each parent (`#parents`: for a link carrying the `entry` token, the `toggle` match inside its closest `dropdown` ancestor within the target; otherwise, for each `list` ancestor strictly inside the target from the link's parent up, the nearest preceding sibling matching `parent`) behind the same door; dispatches `activate.vn.scrollspy` on the host (bubbling, not cancelable, `detail.relatedTarget` the link); returns the door. `#apply` saves a token in the snapshot only when the write changes it, toggles, and returns `#holds`. The rule matches Bootstrap's `_observerCallback` and `_process` (`scrollspy.js`): down picks the lower entry, up picks the higher, an unscrolled root stops at the first, a leaving entry clears its own link, and an activation clears the target and every active target link inside it before writing. No door admits a state the delivery then writes over; a delivery that finds the scrollspy destroyed, its observer replaced, or the link without its token stops writing and dispatching and reads no further entry. The `link` getter returns `#link` while it carries `active`, else `undefined`. Pinned by: "activates the lower entering section scrolling down and the higher one scrolling up, dispatching a bubbling activate event for each", "clears the active link when its section leaves and no other enters, reading no active link", "activates the links that lead to the active one, a nested list parent or a dropdown toggle, and clears them at the next activation", "keeps the first entering section while the root has not scrolled, as Bootstrap does", "writes the token the shipped nav cascade paints as the active pill", "stops activating when a reaction to its parent write destroys it, dispatching nothing and restoring every link", "stops activating when a reaction to the link write removes the token, writing no parent and dispatching nothing", "processes no further entry of a delivery after a listener to its activate event destroys it", each with its rows. Departures the guide must state: `#link` is cleared only by its own section's leaving; the parent walk stays inside the target; a menu link with no toggle activates nothing where Bootstrap throws.

4. **Smooth scroll.** With `smooth`, the target's `click` listener (`#scrollTo`) reads the closest `[href]` ancestor of the clicked element, looks its section up in the map the last refresh built, does nothing for a link with no observed section, else prevents the click's default action and scrolls: with an `HTMLElement` root, `root.scrollTo` to the section's bounding top minus the root's bounding top minus `clientTop` plus the root's `scrollTop`, `behavior: 'smooth'`; otherwise the host document's view to the section's bounding top plus `scrollY`. Pinned by: "scrolls the host smoothly to the section a clicked link names, preventing the click, and leaves a section outside the host alone", "scrolls the document smoothly when the host does not clip its overflow", each with its rows. Departures the guide must state: the nearest `[href]` ancestor where Bootstrap reads the clicked element's own fragment; bounding-rectangle offsets where Bootstrap subtracts `offsetTop` values; the document scrolled to the section's document offset where Bootstrap scrolls the window to the section's offset from the host; the listener bound once at construction where Bootstrap rebinds at each refresh.
