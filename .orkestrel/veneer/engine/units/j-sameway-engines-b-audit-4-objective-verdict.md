Two behavior defects sit outside the narrowly stated claims. Both are source-derived, not executed reproductions.

1. **Replacement cleanup breaks synchronous nested destruction.** The smallest input is a connected ordinary dropdown: complete a show, remove the menu’s `show` token directly, install a closing `beforetoggle` listener that calls `dropdown.destroy()` and immediately reads the placement attributes, then call `show()` again.

   The second show clears `#placement` before destroying it (`Dropdown.ts:268`). Placement aborts its controller before dispatching the closing event (`Placement.ts:243`, `:250`). That abort removes its subscription to the Dropdown signal, because the subscription uses the Placement signal (`Placement.ts:121`; [DOM listener removal](https://dom.spec.whatwg.org/#add-an-event-listener)). The listener’s `dropdown.destroy()` therefore reaches neither the placement through the signal nor through `#placement` (`Dropdown.ts:329`, `:334`).

   The nested destruction returns while `popover`, positioning, side, and anchor writes remain. Placement restores them only after the listener returns (`Placement.ts:261`). This violates the synchronous restoration behavior documented at `guides/veneer.md:1811` and asserted for other destruction paths at `tests/src/browser/Dropdown.test.ts:2018`. The check at `Dropdown.ts:270` stops subsequent show work but cannot repair that earlier return. Keep the replaced placement reachable until its destruction completes, then clear it only if unchanged.

2. **Ordinary Tooltip hide still unlinks the mutable ID.** Start with a connected trigger with a title and no description attribute. Complete a show, change the generated tip’s ID to `replacement`, then hide it. Discard removes the tip but calls `#link(tip.id, false)` (`Tooltip.ts:846`, `:848`). That removes `replacement`, leaves the original linked ID dangling, and clears `#linked` (`:859`). Popover inherits this path. The stopped-show repair does not cover ordinary discard; that path also needs the recorded linked ID.
