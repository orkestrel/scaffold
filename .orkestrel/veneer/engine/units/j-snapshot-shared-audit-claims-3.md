## Claims

Every later use of that target — `#relinquish`, each `#writeBack` in `restore`, the `finally` withdrawal in `restore`, and `clear` — reads the stored key and never derives it again from the element or its current document.
2. **The folding reading is the platform's.** `#folds(owner)` returns true exactly when `owner` is an HTML document, the only case where the DOM's `createElement` lowercases a name and where an HTML element's string attribute accessors match names in ASCII lowercase, whatever the document's content type. A method the document carries of its own does not change the reading. Caching the reading per document is sound because a document's HTML-or-XML type never changes after creation.
3. **The write back names the attribute the save read.** For every target saved and restored while its element stays in one document, the write back reads and writes the same attribute or property the save read. Trace an element that moves between an HTML document and an XML document after the save, in both directions. It aborts its controller, so the `abort` listener it bound on `options.signal` is gone. A later lock on the same document, after a body is added, locks it.
