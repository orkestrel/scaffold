## Per-claim verdicts (numbered as in `j-helpers-audit-claims-2.md`)

**1. `readClosest` (H1) — CONFIRMED.** `helpers.ts:799-808` (diff) defines `readClosest(element, selector, root?)`: `element.closest(selector)`, guard `isInstance(match, HTMLElement)`, then `root === undefined || root.contains(match)`; returns `undefined` on any rejection, no farther-ancestor retry; `SyntaxError` propagates uncaught. Sites: `Delegate.ts` diff shows every `#closest` call site rewritten to `readClosest(target, selector, this.#root)` and `#closest` itself deleted (diff hunk removing lines `-	#closest(target: Element, selector: string): ...`). `#routeTabKey` reads `readClosest(control, this.#tab.selectors.list)` unbounded (`Delegate.ts` diff line "`const list = readClosest(control, this.#tab.selectors.list)`"). `Tab.ts` diff deletes `#list()` and both callers (`#sibling`, `#planInitial`) now call `readClosest(this.#host, this.#selectors.list)`; `#wrapper` reads `readClosest(control, ':is(wrapper, entry)') ?? control`. Test cases in `helpers.test.ts` (`describe('readClosest', ...)`) match the five named behaviors verbatim, and mutation log rows `readClosest applies the containment before the guard...`, `readClosest widens the guard to Element`, `readClosest passes a rejected match to a farther ancestor` each read `EXACT exit=1` with the stated failed counts. Mutation-proof check: each row names a distinct code mutation (order of guard vs. containment; widening the `HTMLElement` guard to `Element`; retrying on rejection) and each row's failed-count and named case differ per mutation, so the suite distinguishes the mutation from the passing case.

[])].find(instanceOf(HTMLElement))`. `Delegate.ts#locateToggle` diff: reads own trigger first via `readClosest`, then `[...readSiblings(container, trigger, false), ...readSiblings(container, trigger, true), ...(container.parentElement?.querySelectorAll(trigger) ?? [])].find((element) => !matchesDisabled(element, disabled))`, then `readClosest(found, trigger, this.#root)`. `ScrollSpy.ts#parents` diff: `const previous = readSiblings(holder, parent, false)[0]`. Test titles in `Delegate.test.ts` ("passes over a disabled toggle before the menu...", "prefers the toggle before the menu...") and `Dropdown.test.ts` ("takes the nearest menu before the toggle...") appear verbatim (diff lines 924, 950, 1046). **3. `readOutermost` (H3) — CONFIRMED.** `helpers.ts` diff: `readOutermost(root, selector)` nests via `root.querySelectorAll(':scope :is(selector) :is(selector)')`, filters `instanceOf(HTMLElement)`, excludes nested and (implicitly) the root itself since `querySelectorAll` never returns the root. `Carousel.ts#items` diff: `return readOutermost(this.#host, this.#selectors.entry)`. `Collapse.ts#siblings` diff: `readOutermost(parent, host + ', ' + transition).filter((element) => element !== this.#host && element.matches(host+shown+', '+transition))`. Test cases in `helpers.test.ts` (`describe('readOutermost', ...)`) match the four named behaviors. Mutation rows "drops the `:is()` wrapper" (`EXACT`) and "excludes no nested match" (`JOINED`) present at log lines 4-5 with distinct failed counts (1 of 55, 3 of 55) and named/joined cases distinguishing each mutation.
