**The source**

The class recurs because snapshot restoration records values and retains pending writes, while each engine separately decides whether it actually acquired a write or promotion, retains the owning resource, and completes reentrant release (`HostSnapshot.ts:100`, `HostSnapshot.ts:136`, `Dropdown.ts:268`, `Placement.ts:248`). One internal acquisition-and-release mechanism that records only actual changes and retains each acquired resource until reentrant release completes would close the unearned records, replacement gap, and promotion-lifetime gaps without adding a public API.

**Claims I could not break**

These are source-review conclusions, not executed confirmations.

- **Stopped-call returns use recorded values and the call’s original identity.** The record helper excludes unchanged writes and preserves the first changed value; rewind reverses those records and checks ownership before each write. (`helpers.ts:950`; `helpers.ts:982`; `Dropdown.ts:395`; `Dropdown.ts:411`.)
- **Ordinary hide and stopped-show placement release retain their field during destruction.** The stopped-show path additionally clears only the same placement. (`Dropdown.ts:400`; `Dropdown.ts:460`.)
- **Snapshot restoration uses saved element identities, normalized keys, values, and priorities.** It does not select a replacement target from consumer-mutated state at release. (`HostSnapshot.ts:101`; `HostSnapshot.ts:128`; `HostSnapshot.ts:310`.)
- **Nested snapshot restoration can finish pending recorded writes.** The retained `#owned` entries and per-record write marker prevent an interrupted restoration from replaying completed writes. (`HostSnapshot.ts:136`; `HostSnapshot.ts:315`; `HostSnapshot.ts:318`.)
- **Registry release cannot remove a replacement owner’s claim.** It compares the recorded engine identity before deletion. (`Registry.ts:44`.)
- **Foreign Placement implementations are not an available Dropdown extension seam.** Dropdown constructs the shipped class directly; its options accept placement settings, not a placement factory or instance. No foreign-only coordination repair follows from this slice. (`Dropdown.ts:420`; `types.ts:1041`.)
