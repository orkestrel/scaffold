## The obligations (each an edit and a proof; red first where the behaviour is new)

- **A. `readOutermost` over its declared domain.** The signature accepts `ParentNode`, and under a `Document` root the platform's `:scope` denotes the document element, so `:scope :is(S) :is(S)` excludes nothing when the document element and the body both match. Compute the nested set from the matches themselves: a match is nested when another match contains it (`matches.some((other) => other !== match && other.contains(match))`), which needs no `:scope` and holds for an `Element`, a `Document`, or a `DocumentFragment` root; keep the `:is()` treatment of a selector list where it still matters (the nesting is now judged on the matches, so the list needs no wrapper; delete the wrapper if nothing reads it). Red first: a case over a fresh HTML document (`document.implementation.createHTMLDocument('')`) whose document element and body both carry the class returns the document element alone; a case over a `DocumentFragment` root with a nested match returns the outer match alone. Keep every existing `readOutermost` case green and the `Carousel` and `Collapse` sites unchanged in behaviour. Rewrite the doc block's remark for the new nesting rule.
- **B. Dropdown light dismissal.** Bootstrap's `clearMenus` closes an open menu through `_completeHide` without reading `isDisabled`; only `show` and `hide` read it. `Dropdown.#lightDismiss` hides through `#conceal`, which calls `#refused(false)`, so an open menu whose toggle reads as disabled stays open on an outside click or a Tab release (`main` already did this for token and `:disabled` toggles; round 2 widened it to anchor toggles). Make light dismissal bypass the disabled reading while keeping its other refusals (destroyed, a change in flight, the menu already hidden, a prevented `hide` event); `show`, `hide`, and `toggle` keep the disabled refusal. Red first: an open menu whose anchor toggle carries `disabled` (shown through the engine before the attribute is written) closes on an outside click, and another closes on focus leaving through a Tab release; record the failing command and count before the fix. The `#### Dropdown` sentence states that light dismissal closes a disabled toggle's open menu as Bootstrap's does.
