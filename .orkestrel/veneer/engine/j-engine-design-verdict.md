Terrain: `units/j-engine-terrain-record.md` (the platform readings in both probe suites, the bench probes, the candidate map's spot checks), `units/j-engine-terrain-distillate.md` (Elements and Mailbox, `grok` session `70dd1223-fe3c-4bcd-ac51-3206c11e139a`), `units/j-engine-orkestrel-2-map.md`. ## Rulings

Where the lanes agreed the ruling names both; where they split it names the lane adopted and the evidence that decided it.

- **R1 The outside is Bootstrap's, the inside is the platform's.** (Both.) Markup, `data-bs-*` attributes, cascade classes, and wire event names are Bootstrap's; the mechanisms underneath are the platform's; a TypeScript member obeys Veneer's naming law and a departure from a Bootstrap member name is recorded in the guide. Explicit construction, a side-effect-free import, `Delegate` as the only data API, one owner per host per class, restore on destroy, one `AbortController` per entity, no mutation after `destroy()`.
- **R2 Wire events.** (Both.) Each plugin dispatches Bootstrap's own names (`show.bs.collapse`, `hidePrevented.bs.modal`, `slid.bs.carousel`, and the rest), bubbling, `cancelable: true` on the pre-change and the completed event alike (Bootstrap's `EventHandler.trigger` shape), with the detail fields Bootstrap hydrates (`relatedTarget`, `clickEvent`, `direction`, `from`, `to`) carried in `detail` and mirrored as own properties on the event (probe 2 `event.ownProperty.readback`). `preventDefault()` on a pre-change event refuses the change; a handler's return value refuses nothing (Bootstrap's own wrapper does not honour `return false`, `dom/event-handler.js`), and the jQuery half of that row is excluded. No `.vn.` alias is dispatched beside a Bootstrap name. `toggle.vn.button` stays as F6 shipped it, non-cancelable (the analyst; the planner's flip to cancelable is refused because Button has no Bootstrap event to mirror). `emitEvent` takes the cancelable flag as a parameter and returns `!defaultPrevented`.
- **R3 Event-map keys mirror Bootstrap's verbs.** (The planner.) `{Entity}EventMap` keys are `show`, `shown`, `hide`, `hidden`, `hidePrevented`, `inserted`, `close`, `closed`, `slide`, `slid`, `activate`, and Button's `toggle`, each key's TSDoc naming the wire event it mirrors, under `.claude/rules/names.md` § General vocabulary's mirrored-name sentence; the frozen `{ENTITY}_EVENTS` table is the declared wire body (`COLLAPSE_EVENTS.shown === 'shown.bs.collapse'`). The analyst's translated vocabulary (`open`, `close`, `prevent`, `insert`, `change`, `remove`) is refused: it makes `close` mean a completed hide on Modal and a pre-change on Alert, and it hands every consumer a second vocabulary for one event.
- **R4 Ownership and lookup.** (Both, the planner's name.) `Registry` (`src/browser/Registry.ts`) holds one `WeakMap` per class; construction claims the host after validation and before any hook can query it, a second claim throws `AppError` `{ENTITY}_HOST_OWNED`, and `destroy()` releases. Every class exposes `static find(host): {Entity}Interface | undefined` (Bootstrap's `getInstance`); `getOrCreateInstance` and `VERSION` are excluded. `Snapshot` (`src/browser/Snapshot.ts`) records each attribute, class token, and inline property an entity first touches and restores it on `destroy()`, keeping later consumer edits.
- **R5 One `Delegate`.** (Both; the analyst's `components` selection refused.) `Delegate` routes every Bootstrap data API on its root — `data-bs-toggle` (`button`, `collapse`, `dropdown`, `tab`, `pill`, `list`, `modal`, `offcanvas`), `data-bs-dismiss` (`alert`, `modal`, `offcanvas`, `toast`), `data-bs-slide` and `data-bs-slide-to`, the dropdown and tab `keydown` routes (Bootstrap's document-level data API, `dropdown.js:440-451`), and a construction-time scan for `[data-bs-spy="scroll"]`, `[data-bs-ride="carousel"]`, and `.offcanvas.show` — acquiring an engine it constructs and driving one a consumer constructed through `find`. Release on removal: the delegate observes its root (`MutationObserver`, `childList`, `subtree`) while it owns at least one engine and, at each delivery, destroys and releases every owned engine whose host the root no longer contains; a host removed and reinserted within one task keeps its engine (probe 2 `observer.removeReinsertSameTask`). This replaces the next-click release F4 recorded and closes § Carriers audit claim 4. Each new route lands with its component.
- **R6 Transition completion.** (Both.) `settleAnimations(element, signal)` in `helpers.ts` reads `element.getAnimations()`, leaves out infinite and paused animations, awaits each `finished`, treats a rejected `finished` as settled (probe 1 `transition.cancel`, `transition.removeMidway`), re-reads until the list is empty, and resolves at once when the signal aborts; `reflow(element)` forces layout before a class or dimension write so the transition exists in the same task (probe 2 `transition.sameTask.readBeforeChange`). No animation, no `.fade` or `.slide`, and reduced motion complete in a microtask (probe 1 `transition.reducedMotionZero`). A show or hide call while one is in flight resolves `false` and does nothing; Carousel's `slide(index)` alone queues until `slid`, as `carousel.js:175-178` does (the planner; the analyst's "ignored" departure refused on that source). `destroy()` mid-flight aborts the settle, fires no completed event, and restores. Every state-changing method returns `Promise<boolean>` created before any await (`true` the change happened, `false` refused or prevented); `TRANSITION_END` emulation and every fixed timer stay excluded. Timers remain for tooltip delay, toast lifetime, and carousel intervals only.
- **R7 Escape is Bootstrap's `keydown`; `CloseWatcher` is deferred.** (The Orchestrator, on probe 2.) Two free watchers close together on one Escape (`closeWatcher.second.freeWatcher`), so a watcher per shown overlay cannot give the topmost overlay alone the key, and the Escape key grants no activation that would make a fresh watcher's `cancel` cancelable. Modal and Offcanvas listen for `keydown` Escape on their own element (`modal.js:207-218`), Dropdown through the delegate's keydown route and its own toggle, Tooltip and Popover through the hint dismissal only where R9 names it. `CloseWatcher` is recorded as a platform feature measured and not adopted, with the grouping reading as the reason; a later unit may adopt one watcher per document if a consumer needs a non-keyboard close request.
- **R8 Modal and Offcanvas stay in flow.** (The planner.) Both keep the cascade's `z-index` ladder, the cascade's own backdrop element (`Backdrop`, `src/browser/Backdrop.ts`, appending `.modal-backdrop` or `.offcanvas-backdrop` with `.fade` and `.show`), focus containment through `inert` (`Isolation`, `src/browser/Isolation.ts`: at show, every element outside the host's ancestor chain becomes inert, later insertions at each isolated level are observed, and `destroy()` restores each value and returns focus to the previously focused element when it is connected and visible; `focus: false` disables it; Offcanvas isolates only when it has a backdrop or does not scroll), and scroll lock (`ScrollLock`, `src/browser/ScrollLock.ts`: Bootstrap's `ScrollBarHelper` — `overflow: hidden`, the measured scrollbar width added to `padding-right` on `body`, `.fixed-top`, `.fixed-bottom`, `.is-fixed`, and `.sticky-top`, subtracted from `margin-right` on `.sticky-top`, `body.modal-open`, reference-counted per document, restored on release; probe 1 `dialog.showModal.scrollLock` shows the platform locks nothing). The analyst's promotion of the modal to the top layer is refused: a toast at `z-index` 1090 must stay above a modal at 1055 as in Bootstrap, and `.offcanvas-lg` stays in flow at its breakpoint. Light dismiss is Bootstrap's own check (`mousedown` then `click` on the host itself); `backdrop: 'static'` fires `hidePrevented` and bounces `.modal-static`.
- **R9 Floating surfaces take the top layer through the `popover` attribute, with the UA reset owned by the engine.** (Both, bounded by probe 2.) `Placement` (`src/browser/Placement.ts`) promotes the dropdown menu and the popover tip with `popover="manual"` and the tooltip tip with `popover="hint"` at show and removes the attribute after `hidden`; it writes `anchor-name` on the reference and `position-anchor`, `position-area`, `position-try-fallbacks`, `position-try-order: normal`, `inset: auto`, and the offset margin on the floating element, through inline declarations restored by `Snapshot`; it maps Bootstrap's placement strings to physical `position-area` keywords (`auto` to a flip fallback list), writes `data-popper-placement` from the side it measures by rectangle comparison after open, on the reference's `ResizeObserver`, and on `scrollend`, writes `data-bs-popper="static"` with no promotion and no anchoring for `display: 'static'` and a menu inside `.navbar`, reads `--bs-position` (R7 of the disclosure verdict) and centres `.dropdown-center` and `.dropup-center` (R9 there). Probe 2 `ua.popover.open` reads the UA defaults a promoted element inherits (`position: fixed; inset: 0; margin: auto; padding: 4px; border: 3px solid black; background white; overflow: auto; width: fit-content`): Bootstrap's own `.dropdown-menu`, `.tooltip`, and `.popover` rules override `position`, `margin`, `padding`, `border`, and `background`, the engine's inline `inset: auto` overrides the inset, and each promoted component's proof reads the computed border, padding, background, margin, and overflow of the promoted element against the unpromoted one under the same cascade, so any UA leak reddens it. A hint tooltip's platform dismissal is bridged through the cancelable `beforetoggle` into `hide.bs.tooltip`, so a prevented hide keeps the tip; the popover tip and the dropdown menu stay `manual` and implement Bootstrap's `autoClose` matrix themselves (`popover="auto"` cannot express `inside` and `outside`). Popper's `boundary` is accepted as a wire key and ignored (the top layer has no clipping parent), `popperConfig` is accepted as a wire key, never a TypeScript option, and not executed; both sit beside the affected option in the guide under the existing "accepted difference" sentence.
- **R10 Content.** (Both; `sanitizeFn` per the analyst.) `html: false` writes `textContent`; `html: true` writes through `Element.setHTML` with a `Sanitizer` built from Bootstrap's `DefaultAllowlist` (`util/sanitizer.js:11-46`: the listed tags, the per-tag attributes, `class`, `dir`, `id`, `lang`, `role`, and every `aria-*` name the input carries, added by `allowAttribute` because the wildcard matches nothing and the default baseline drops `img`, `class`, `id`, `role`, and `aria-*`, probe 2 `sanitizer.default.attributes`, `sanitizer.custom.ariaWildcard`; `setDataAttributes(false)` because the allowlist admits no `data-*`); `sanitize.filter` (Bootstrap's `sanitizeFn`) is the consumer's trusted replacement and its result is written through `setHTMLUnsafe`; `sanitize.enabled: false` writes through `setHTMLUnsafe`. The template is parsed and filled on a detached element with the same sanitizer (`buildTip`, `fillSlot` in `helpers.ts`), a `null` or empty slot value removes the slot element, an element value is moved in and moved back on `destroy()`, and `customClass` is added. Bootstrap's URL floor and the platform's floor differ in shape (the platform drops a `javascript:` attribute and keeps the element); the departure is recorded on the sanitizer option. `@orkestrel/html` and `@orkestrel/template` are not used.
- **R11 Options and attributes.** (Both, the planner's paths.) Each class merges `{ENTITY}_DEFAULTS`, then `data-bs-config` JSON, then the `data-bs-*` keys the entity declares (`parse{Entity}Attributes` in `src/browser/parsers.ts`), then the constructor object; explicit `false` and `0` survive; a present attribute that fails coercion throws `AppError` `{ENTITY}_OPTION_INVALID`; an undeclared key is ignored. Tooltip and Popover read no `data-bs-config` and refuse `sanitize`, `allowList`, and `sanitizeFn` from attributes (`tooltip.js:539-555`). Every entity accepts `on?: {Entity}Hooks` and `signal?: AbortSignal` (an aborted signal destroys the entity). Option paths: one-word Bootstrap keys stay verbatim (`parent`, `toggle`, `backdrop` as a boolean, `focus`, `scroll`, `animation`, `autohide`, `delay`, `html`, `title`, `content`, `container`, `target`, `interval`, `keyboard`, `pause`, `touch`, `wrap`, `reference`, `selector`); compound keys group by entity noun — `dismiss: { inside, outside }` for `autoClose`, `dismiss: { backdrop, escape }` for `backdrop: 'static'` and `keyboard: false`, `placement: { position, offset, fallbacks, static }`, `delay: { show, hide }`, `trigger: { hover, focus, click }` (`manual` is all three false), `sanitize: { enabled, allow, filter }`, `tip: { template, class }`, `intersection: { margin, threshold }` with `data-bs-offset` converted by Bootstrap's formula, `smooth` for `smoothScroll`, and Carousel's `ride?: 'load' | 'interaction'` with absence meaning never.
- **R12 Members.** (Both, reconciled.) `dispose` is `destroy`; `getInstance` is `static find`; `handleUpdate` and Popper's update are `update`; `setContent` is `fill`; `isShown` is the `shown` getter; `toggleEnabled` is the `enabled` getter with `enable` and `disable`; `prev` is `previous`; `to(index)` is `slide(index)` (a verb that names the operation and its own event); `cycle` is `start` and `pause` stays (`start` begins or restarts, so no `resume`); `nextWhenVisible` is internal. Every other verb is Bootstrap's: `show`, `hide`, `toggle`, `close`, `next`, `refresh`, `update`, `enable`, `disable`. `Popover extends Tooltip` and reads a static `profile` through `new.target` (name, wire table, defaults, template, slots), so one engine serves both with no protected member; the analyst's abstract `Hint` base is refused because a `#`-only class cannot share state with a subclass.
- **R13 Placement of files.** (The analyst's reading of the rule.) Every class is a lone entity and sits flat at `src/browser/`: the seed's `Button.ts`, `ColorMode.ts`, and `Delegate.ts` unmoved; `Collapse.ts`, `Dropdown.ts`, `Tab.ts`, `ScrollSpy.ts`, `Modal.ts`, `Offcanvas.ts`, `Tooltip.ts`, `Popover.ts`, `Alert.ts`, `Toast.ts`, `Carousel.ts`; and the mechanisms `Registry.ts`, `Snapshot.ts`, `Isolation.ts`, `Backdrop.ts`, `ScrollLock.ts`, `Placement.ts`, `Swipe.ts`. `.claude/rules/architecture.md` § Entity subfolders nests only one entity's family (entity plus manager, or sibling implementations of one contract), and twelve distinct entities are not one family; the planner's `components/` folder is refused on that text. Centralized files stay at the root: `types.ts` (every contract), `constants.ts` (wire tables, selectors, defaults, the allowlist, the templates), `helpers.ts`, `validators.ts` (`isHost` replaces `isButtonHost` with every consumer updated; `is{Entity}Event` guards), `parsers.ts` (new). `src/core/types.ts` gains nothing. Tests mirror each file under `tests/src/browser/`.
- **R14 The `@orkestrel/*` matrix.** (Both.) `contract` stays the sole runtime dependency and is reused for guards and combinators (`isInstance`, `literalOf`, `Guard`, `isRecord`, `isString`, `isFunction`); `emitter` is excluded (its `emit` returns `void` and cannot carry a veto; the DOM event model is the Browser/DOM variant `.claude/rules/patterns.md` names); `abort` is excluded (the native `AbortController` and `AbortSignal.any` cover the lifetime); `timeout` is excluded (component-owned delays are native timers, and its rearming and parent-abort semantics would need translation); `queue` is excluded (a job queue answers no mechanism and carries `database`); `html` is excluded (an AST round trip against a live element, 138 KB, a `node:` reference in its built entry); `template` is excluded (string substitution is not selector-slot DOM filling). No `package.json` change; the user's ruling is recorded here as "no candidate enters" and is put to the user with this verdict. `@orkestrel/test`'s `createRecorder`, `createRecorders`, `waitForCondition`, `waitForEvent`, `waitForAbort`, and `@orkestrel/test/browser`'s `build`, `mount`, and `waitForAnimations` are the proofs' primitives.

Carried, flipping to `shipped` when the carrier lands: the config merge and type check, `Manipulator.getDataAttributes` (declared keys only), `SelectorEngine.getSelector` and its `getElementFromSelector`, `getMultipleElementsFromSelector`, and `focusableChildren` (as `readTarget`, `readTargets`, `collectFocusable`), `Data.set/get/remove` (as `Registry`), `enableDismissTrigger` (the delegate's dismiss route), the sanitizer allowlist and `sanitizeFn`, native `querySelector` with `CSS.escape`, and the utilities `getUID`, `getElement`, `isElement`, `isVisible`, `isDisabled`, `reflow`, `getNextActiveElement` (as `generateId`, `isHost`, `checkVisibility()`, `reflow`, `computeNeighbor`).
