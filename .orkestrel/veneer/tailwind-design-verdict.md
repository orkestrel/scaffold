## The user's rulings (2026-10-01)

1. **The sheet ships compatibility changes only.** Veneer does not re-export its own version of Tailwind the way it recreates Bootstrap; `./tailwindcss` provides only the compatibility changes needed so that Tailwind's styles align with Bootstrap and do not fight it.
2. **The Tailwind map stays internal to its surface.** The map (the token names and the class names Tailwind generates) is not put into `src/core` and is not exported; it is kept inside the `tailwindcss` surface for determinism, because the main framework is Bootstrap and Tailwind is a compatibility layer. Only the compatibility styles are bundled and exported. This is the one map that remains internal; the `bootstrap` groups and the later `veneer` groups stay in `src/core`.
3. **No JavaScript comparison export.** The comparison lives beside the map.
4. **The inventory writer stays uncommitted under `tmp/units/`**, regenerated from its brief on a Tailwind bump; the committed projection pins the record.
5. **Preflight is handled under what Tailwind provides (2026-10-01, on the evidence readings).** Map it and attack it the way the classes are mapped: the record carries Tailwind's own compiled reset, the departures from lifted Bootstrap are measured rows, the compatibility sheet fixes them (the preflight mirror in `base`), and a limit that arises (a Tailwind utility relying on a preflight declaration) is addressed as it arises through the exemption table, never by omitting preflight.
6. **The record is minified.** The 17 MB generated record is committed compact as `oracle.min.json`; `oxfmt` does not skip a `.min.` file by default (measured 2026-10-01 on scratch `.min.json` and `.min.js` files), so `.prettierignore` carries `*.min.*` for minified generated records, in scaffold's template and in veneer, and authored source never takes the suffix.

The rulings from the brief stand: map Tailwind so the two maps compare deterministically (repeated, similar, overlap, drift, incompatible); every proof reads the real package; the record is lossless and digest-bound; nothing is ignored or suppressed.
