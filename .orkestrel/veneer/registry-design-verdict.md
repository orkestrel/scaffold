## The user's rulings (2026-10-01)

1. **Variants stay with their component.** Components stay together: a modifier specific to a component is a variant of it and remains part of it, because modifiers are broad and general while variants are modifiers specific to something like a component; `bg-blue` and `btn-primary` are both modifiers, but `bg-blue` is general to any background and `btn-primary` is specialised for a button.
2. **Composables are the general engine states.** The same rule by specificity: a general engine-set name such as `show`, `active`, or `fade` is a composable; a name specific to a modal or a carousel, especially in its name, belongs with that component as a variant.

## Rulings per question

1. **Shape.** One `CLASS_NAMES` registry keyed by face, then category (`components`, `utilities`, `modifiers`, `composables`; a later face adds `elements` and `surfaces` only where it declares them), then the hyphen segments of the name, frozen at every level with `as const` leaves, the token registry's law: a numeric or digit-led segment is a quoted key (`col.md['6']`, `w['25']`, `ratio['16x9']`); a name that is the proper prefix of another name in its category subtree sits under a terminal `base` key (`components.btn.base` is `btn`); only a terminal `base` adds nothing, so a name whose own last segment is `base` writes it twice (`utilities.lh.base.base` is `lh-base`, the one such name in Bootstrap); the generator and the projection refuse two names on one path, a leaf beside a group of the same key, and `X` beside `X-base`. Sorted tuples (one judgment) are refused: no proof gain over the amended tree, and the user ruled the tree for tokens. A reserved-segment encoding (`$base`, `$hex`) is refused for Bootstrap: one law for tokens and classes, no second alphabet; the Tailwind chunk rules its own key law for names carrying `:`, `/`, `[`, or a leading `-`, under the existing empty-key refusal.
2. **Category axis.** A pure function of the committed inventory and a committed engine fixture, first match wins, with `ROOTS` the set of names declared outside the utilities API region by a rule that sets at least one non-custom property and that are the proper hyphen prefix of another declared name:
   1. **root**: the name is in `ROOTS` → `components` (a root stays a component even when the engine writes it: `collapse`, `modal`, `carousel`);
   2. **variant**: the name has a proper hyphen prefix in `ROOTS` → `components`, beneath that root (`btn-primary`, `btn-lg`, `alert-danger`, `table-striped`, `ratio-16x9`, `focus-ring-primary`, `navbar-dark`, `modal-static`, `modal-backdrop`, `offcanvas-backdrop`, `carousel-item-next`, `collapse-horizontal`, `list-group-item-primary`);
   3. **modifier**: every rule whose selector carries the name declares custom properties only → `modifiers` (`bg-opacity-50`, `text-opacity-*`, `border-opacity-*`, `link-opacity-*`, `link-offset-*`, `link-underline-*`, `g-*`, `gx-*`, `gy-*`); the unit measures the names this rule files and reports any such token no rule reads;
   4. **composable**: the engine fixture holds a write (`classList.add`, `remove`, `toggle`, or a `className =` write) for the name → `composables` (`show`, `active`, `fade`, `showing`, `hiding`, `collapsing`, `collapsed`, `pointer-event`, `bs-tooltip-auto`, `bs-popover-auto`); a name the engine only tests is not a composable;
   5. **utility**: every site of the name is in the utilities API region → `utilities`;
   6. **component**: every site is outside that region → `components`;
   7. refused: sites in the API region and another region (zero names today).
   Every one of the 2025 names the inventory declares in a style-rule selector is a member, compound-only names included (`collapsed`, `accordion-flush`); keyframe frames are not selectors; a name the engine writes that no rule declares (`modal-open`, the toast `hide`) is not a member. Reboot's `h1` to `h6`, `mark`, and `small` are components. The test-side member for the axis is `category`.
3. **Types.** `RegistryLeaf<TNode>` replaces `TokenLeaf` with the same body (a qualified name, so the fleet `surface` rule has no bare `Leaf` to claim); `TokenName` is `RegistryLeaf<TokenMap>`; `ClassMap` is `typeof CLASS_NAMES`; `ClassName` is `RegistryLeaf<ClassMap>`; no category union and no per-category name type are exported, because `keyof ClassMap['bootstrap']` and `RegistryLeaf<ClassMap['bootstrap']['utilities']>` cover them. The `prove` claim: `const name: ClassName = 'appended-control'` fails to typecheck and `'btn'` passes.
4. **Proofs.** Projections in `tests/setup.ts` with proofs on the handwritten sample: `collectSelectorClasses(selector)` (the one lexer: strips quoted strings and attribute brackets, admits a leading `-`, decodes CSS escapes including hex, refuses unsupported syntax), `joinKeys(path)` (drops a terminal `base`), `collectPaths(names)` (the forward canonical path, throwing on a collision, a leaf-group conflict, or an empty segment), `collectInventoryClasses(record, engine)` returning `{ name, category, sites }` sorted by code unit; `EngineRecord` and `isEngineRecord`; `readBootstrapEngine(path?)` in `tests/setupServer.ts` pinning each cited file's SHA-256; `collectSheetClasses(sheet)` in `tests/setupStyles.ts` over every `CSSStyleRule.selectorText` at every depth and layer with a `CSS.escape` round trip. Cases in `tests/src/bootstrap/index.test.ts`: every class leaf pinned to the inventory both ways (2025; renamed and appended controls); every category and key path derived from the inventory (mis-keyed, superfluous `base`, moved-category, hyphenated, empty, and planted `lh` controls); every leaf pinned to the built sheet both ways and to the bundled sheet's CSSOM (appended-rule control); the token reverse check switched to `joinKeys`.
