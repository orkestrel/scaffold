# Tailwind flip: design verdict

The Orchestrator rules the design round of 2026-10-04 (`design/`): three blind Opus planners (`proposal-thin-layer.md`, `proposal-tuned-build.md`, `proposal-consumer-proof.md`), two Opus judges (`judge-mechanism.md`, `judge-consumer.md`), and a completeness critic (`critic.md`), over `brief.md` and `measurements.md`. Both judges rank `consumer-proof` first, `tuned-build` second, `thin-layer` third, and both refuse the counter mechanism on the same measured ground. This verdict adopts `consumer-proof` as the base with the grafts both judges name, resolves the critic's gaps, and applies the recommended default to every ruling the user has not made, so the units can open; § 10 lists those defaults for the user to confirm or reverse. The objective check (§ 11) ran on 2026-10-04 (`design/objective-check.md`); its corrections are applied in place and listed in § 12.

## 2. Mechanism

### Sass

`src/bootstrap/_mixins.scss` gains four `!default` switches that `_tokens.scss` configures as it configures `$layered`, with defaults that emit the drop-in and lifted forms byte for byte:

- `$withhold: ()` names the classes whose exact `.NAME` utility rules the `utility` mixin skips, with their `local-vars` halves.
- `$reset: false` sends the reboot's element rules to `@layer reset` through a `reboot` mixin that wraps `@content` in `reset` when on and in `layer` otherwise.
- `$curated: ()` names the component classes whose elements keep the reboot: a `curate` mixin emits, after each reboot rule, a copy inside `bootstrap` whose selector `restrict(&, $curated)` keeps every class compound (`.h1`) and restricts every element compound to `TAG:where(.CLASS, ...)`, built with `selector.unify` so a pseudo-element keeps its place (`*:where(.card-text)::before`), and emits nothing when no compound remains.
- `$restored: ()` maps selectors to longhands that read `revert` inside `bootstrap`, emitted once by a `restore` mixin at the end of `_reset.scss`.

`_reset.scss` swaps `@include layer` for `@include reboot`, wraps each rule's declarations in `@include curate`, guards the `[hidden]` rule with `@if not $reset`, and ends with `@include restore`. `curate` emits a copy only for a rule with at least one normal declaration and a satisfiable restricted selector (`a:not([href]):not([class])` restricted to a class is unsatisfiable and produces no copy), and the copy never re-emits an `unlayer` declaration, so the datalist rule stays single and unlayered. `_tokens.scss` refuses `$reset: true` with `$layered: false` through `@error`. `src/bootstrap/index.scss` keeps `@forward 'tokens' show $layered` alone. `src/tailwindcss/_tokens.scss` declares `$shared` (the 192, sorted by code unit), `$curation`, and `$defaults`, then `@use '../bootstrap/tokens' with ($withhold: $shared, $reset: true, $curated: $curation, $restored: $defaults)`, then the 1833-name `@source not inline(...)`. `src/tailwindcss/index.scss` loads `tokens`, then `../bootstrap/reset`, `../bootstrap/elements`, `../bootstrap/components`, `../bootstrap/utilities`, then its own empty `elements`, `components`, and `utilities` barrels. `src/tailwindcss/_reset.scss` is deleted (the face owns no reset). The TypeScript twin `restrictSelector` in `tests/setupStyles.ts` reproduces `restrict` for the derivation proof.
