## 4. Mapping to Veneer subjects

Veneer’s tip today is one class for both profiles (`src/browser/types.ts:2162`, `src/browser/Tip.ts:33-34`). `show` builds a template node, sets `aria-describedby`, appends it, and constructs `Placement` (`src/browser/Tip.ts:148-216`). The popover template is a `div` with `role="tooltip"`, a header, and a body (`src/browser/constants.ts:249`). Triggers are click, hover, and focus on the host (`src/browser/Tip.ts:79-94`). A modal `hide` listener calls `hide` (`src/browser/Tip.ts:95-97`). It does not call the Popover API. `Placement` writes `anchor-name` and `position-anchor`, then sets `position-area` and `position-try-fallbacks` to `none`, measures, and switches the floater to `position: fixed` (`src/browser/Placement.ts:206-224`). Updates wait one frame and a zero timeout (`src/browser/Placement.ts:138-148`) and listen to `ResizeObserver`, capture-phase scroll, and `resize` (`src/browser/Placement.ts:107-124`).
