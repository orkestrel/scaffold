## 2. API shapes

Blank-slate split, from `elements:AGENTS.md:70-74` and `elements:AGENTS.md:473-495`, and from the factories: the `create*` closure is the behavior; a `use*` composable is a Vue ref adapter. Public option keys are single words; related keys share one object (`dismiss`, `scroll`, `validate`, `autoplay`, `intersection`). Defaults are the factory’s `??` expressions, inline, not a separate defaults module. The `on` map is partial and applied with `bindEventMap` (`AGENTS.md:479-483`). `dispatch` is cancelable and returns false after `preventDefault`; `emit` is not cancelable (`AGENTS.md:479-480`). Names are `elements:{source}:{verb}` on the host element (`AGENTS.md:485`). State the caller sees is a `readonly` ref from `@vue/reactivity`. Construction opens an `effectScope` except `createTheme`, which shares `theme.ts`. `destroy` is on the factory. The three adapters read (`useDialog.ts:44-49`, `useAside.ts:44-49`, `usePopover.ts:28`) return forwarded methods and no `destroy`; Vue `onCleanup` calls `instance.destroy()`. `elements:src/browser/composables/index.ts:1-20` lists the other adapters; their bodies were not re-read.
